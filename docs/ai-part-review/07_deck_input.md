## 0. 이번 판에서 바뀐 핵심 메시지 (발표 전체에 걸침)

1. **「AI 를 넣으면 좋아진다」가 아니라 「재 보고, 좋은 곳에만 넣었다」** — 의미 검색은 넣었고(+12문항), 리랭커·RRF 는 재 보고 뺐고, 브리핑 판단은 모델이 0/9 라 규칙으로 돌렸다
2. **우리 평가셋의 1.0 은 상한 — 그래서 남의 데이터로 다시 쟀다**(실제 상담 1만 건 · 공개 욕설 데이터)
3. 개인정보: **STT 이후, 저장과 AI 판단에는 마스킹본만** · 상담원 화면은 원문 + 강조 · 전사는 암호화(10-06 변경)

### [4] 파이프라인 — 한눈에
`음성 → Google STT(외부) → ①마스킹(규칙 ∪ NER) → ②검색 시점(규칙) → ③조항 검색(KoE5) → ④필요서류 판정(규칙표 29조항) → 상담원 화면`
`상담원 발화 → ⑤컴플라이언스(규칙 24) · 고객 발화 → ⑥폭언(사전 59) · 통화 끝 → ⑦요약(kanana 2.1B, 검사 후 폴백) · 받기 전 → ⑧브리핑(규칙)`
- 저장·AI 판단 = 마스킹본 / 화면 = 원문 + 가릴 자리 강조 / 전사 = AES-256 암호화 · 운영은 CPU 노드 1대(GPU 없음)
- 음성 → Google STT: Google 은 기본값에서 음성·전사를 기록하지 않는다(공식 문서) · 우리는 기록 옵트인을 켜지 않았다(코드 기준)
### [5] 파이프라인 — 상세: 모델이 하는 일 셋(임베딩 · 이름·주소 인식 · 요약 문장) vs 규칙이 하는 일 전부 · 「마스킹은 규칙 ∪ 모델 — 모델은 더 가리기만」 · 근거 조항 ID 가 응답에 실린다(`DASAN-MANUAL-1.4` 등)
