**Q10. NER 은 모델이 판정하는 것 아닌가?** — **A + D**

- 답변: 「NER 은 '어디를 더 가릴지'만 제안합니다. 규칙이 찾은 건 모델이 못 풉니다. 그래서 모델이 틀리면 결과는 '더 가린다' 쪽으로만 틀리고, 보호가 약해지는 쪽으로는 못 틀립니다.」
- 반영: 「판정은 규칙」 문장 옆에 「(마스킹: 규칙 ∪ 모델 — 모델은 더 가리기만)」
