## 2. 부탁드리는 것 — 우선순위

### P0 — 이게 없으면 영상을 못 찍습니다
1. **`callId` 덮어쓰기 버그** (`w6-close-callid-missing`) — 미발동 추천은 `call_id` 가 없는데 파서가 `""` 로 채우고(`lib/ws/realCallMediatorClient.ts:384`) 스토어가 그걸로 `callId` 를 덮어씀(`store/callStore.ts:476,491`). 비었거나 없는 `call_id` 로는 **절대 덮어쓰지 않게**.
2. **컴플라이언스 경고 화면** (`w6-compliance-alert-ui`) — 서버 `compliance` 메시지(`rule_code`·`phrase`·`alternative_source`)를 **상담원 발화 줄에** 경고 + 권장 대체 표현(근거 조항)으로. `compliance_unavailable` 이면 「탐지 미동작」으로(조용히 초록이 되지 않게). **라이브 모드에서는 로컬 목업 규칙(`detectComplianceRisk`)을 끄기.** C-4 는 「의학적 안심 발언」(`decisions/211`).
3. **시연(관전) 모드 — 모달·마이크 없이 통화 보기** (`w7-call-ui-loose-ends`) — `?call_id=` 로 들어오고 `call_token` 이 없으면 「통화받기」 모달을 띄우지 않고 마이크도 열지 않는 **보기 전용** 진입.
4. **목업 「블랙컨슈머 분류 · 관리자에게 전송됨」 카드**를 라이브 모드에서 숨기기 (`w6-qa-ui-defects-three` 셋째) — 실제로 아무 데도 안 보냄.
5. **`?call_mediator=` 오버라이드 배너가 토큰을 가리게** — 쿼리 `token=` 값은 `***` 로.
6. **소개 페이지 「92%」「38%」 삭제** (`w6-platform-unmeasured-numbers`, `apps/platform/src/components/PrivacySection.tsx:33-34`).

### P1 — 있으면 영상이 훨씬 좋아집니다
7. **콜 가드 여러 갈래 저장** (`w6-qa-ui-defects-three` 둘째) — 한 발화에 모욕+성적이면 둘 다, **위기 신호(distress)는 절대 다른 갈래에 덮이지 않게**(`callStore.ts:625-632`).
8. **「미측정(null)」을 「0건」으로 보이지 않게** (`w6-qa-ui-defects-three` 첫째, `decisions/316`).
9. **추천 요청별 「관련 문서 없음」** — `fired:true, cards:[]` 일 때 그 발화에 짧게 표시. 그리고 첫 인사 뒤 「이 민원 유형은 서류 안내 대상이 아닙니다」는 **「아직 문의 내용이 없습니다」** 같은 사실 문구로.
10. **통화 후 요약에 문의 유형 칩** — 서버 D-2 가 이제 유형을 채웁니다(`decisions/323`: 대중교통·상하수도·일반행정·감염병·재난·생계 지원금).
11. **「⚠ 경고」 알약** — 늘 비활성인 버튼이면 없애거나, 마스킹 표시(🔒)로 바꾸기.

### P2 — 선행 작업이 있어서 나중에
12. **베테랑 배정(J-5) 결과 표시** (`w6-routing-result-ui`) — 지금은 WS 메시지가 없습니다. 미디에이터가 `routing` 메시지를 방송하도록 먼저 바뀌어야 합니다(정성윤·류준 쪽). 형식이 정해지면 따로 알려드리겠습니다.
13. (선택) **시연용 지연 표시** — 추천 메시지에 이미 실려 오는 `retrieval_ms` 를 작게(디버그 토글). 파서가 지금 버립니다.

### 만들지 말 것
- **번역 화면 흉내** — A-5 1차 범위는 「서툰 한국어를 받아 적기」까지입니다. 번역·TTS 는 없습니다.
- 위험도 점수·확률·「안전합니다」 류 문구(부록 A-1).
- 목업 데이터로 빈칸 채우기(대기화면 KPI 는 이미 「디자인 목업」 표기 — 영상에서 길게 안 찍겠습니다).

## 3. 서희님 쪽이 아닌 것 (류준·정성윤이 처리)

- **엉뚱한 필요서류 체크리스트** — 미디에이터가 절차를 고르는 규칙 문제라 류준이 고치는 중입니다(`w6-procedure-noise-redesign`).
- **운영 번들 재배포** — Vercel 하루 한도에 걸려 09-22 수정이 운영에 안 나갔습니다(`w6-vercel-redeploy`, 정성윤). 녹화 전에 한 번 확인하거나, `apps/call` 을 로컬 `vite` 로 띄워 찍습니다.
- **읽기 경로 인증**(`w6-read-path-auth`, 장민석) — 서버에서 켜지면 상담기록·자막 조회에 토큰이 필요합니다(`w6-read-path-token-ui`). **녹화 전에는 켜지지 않게** 맞추겠습니다.
- **외국인 발화 음성 인식** — 재생기는 글자를 흘려서 STT 를 거치지 않습니다. 「서툰 한국어를 알아듣는다」를 음성으로 보이려면 녹음 파일을 실제 STT 경로(`scripts/stream_wav.ts`)로 흘려야 합니다(류준).
