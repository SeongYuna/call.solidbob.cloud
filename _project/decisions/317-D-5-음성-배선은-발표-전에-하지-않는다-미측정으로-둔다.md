# 317 — D-5 음성 이상치의 요청 경로 배선은 발표 전에 하지 않는다 · 「미측정」으로 둔다

**날짜**: 2026-09-22
**작성**: 장민석 (브랜치 `server`)
**관련**: `decisions/203`(D-5 통화 온도) · `316`(온도 이상 NULL = 미측정) · 절대 원칙 2·10 · 티켓 `w7-d5-server-wiring` · 미결 「D-5 음성 이상치 저장이 서버에서 배선되지 않는다」

## 맥락

서버 요청 경로에서 `voice_outlier` 에 쓰는 곳이 없어 블랙리스트 근거의 온도 이상이 **운영에서 늘 0** 이었다(09-22 확인).
`316` 으로 0 대신 「미측정」(NULL)을 내게 했다. 남은 질문은 **실제로 배선할지**다.
류준 님 조사(09-22): 콜 미디에이터의 서버 호출 6개가 전부 텍스트만 싣는다 — 새 API 없이는 불가능하다.
제안은 확정 발화마다 `POST /hub/voice-samples` 로 음성을 보내 서버가 F0 만 뽑고 오디오는 버리는 것이다.

## 선택지

| 후보 | 판단 |
|---|---|
| **발표 전에는 하지 않는다 — 「미측정」으로 둔다** | 지금 상태 그대로. 화면이 「미측정」을 말하면 거짓이 없다 |
| `POST /hub/voice-samples` 로 배선한다 | 새 API(오디오 업로드) · 미디에이터 수정 · 서버 파드에서 F0 추출(CPU) · 오디오 즉시 폐기의 SEC-1 검증이 함께 들어온다. **음성 골든셋이 0건**이라 붙여도 판정 품질은 측정 불가다 |

## 결정 (사용자 선택, 2026-09-22)

**발표 전에는 배선하지 않는다.** 블랙리스트 근거의 온도 이상은 「미측정」으로 나간다(`316`). 발표에서도 D-5 는 「요청 경로 미배선 · 판정 품질 측정 불가」로 적는다.

## 근거

- 배선해도 **잴 수 없는 값을 운영 화면에 올리는 것**이 된다 — 음성 골든셋이 없어 이상치 판정이 맞는지 모른다(절대 원칙 10)
- 남은 기간의 임계 경로(6주차 판정 → 시연 → 발표)에 없다. 새 API·미디에이터·오디오 취급이 한꺼번에 들어오는 크기다
- `316` 으로 「0 = 이상 없음」이라는 오독은 이미 막았다 — 배선하지 않아도 거짓 표시는 없다

## 되돌리는 법

음성 골든셋이 생기고 시간이 되면 류준 님 제안(`POST /hub/voice-samples`)으로 배선하고, `hub/dependencies/blacklist_provider.py` 의 `voice_outliers_wired` 를 `True` 로 바꾼다.
