# 132. 확장 모듈(F-1·G·H·I)은 착수하지 않는다 — 남은 기간은 시연과 마감에 쓴다

- 날짜: 2026-09-22
- 작성: 정성윤
- 상태: 채택 (**09-30 판정과 무관하게** — 아래 「근거」)
- 관련: `decisions/129`(8스프린트는 10-14 에 끝난다) · `022`(6주차 종료 시점 판정 원문 복원) · `201`(에스컬레이션 보류) · `125`(F-2 는 구현 완결)
- 티켓: `w8-extension-pick`(이 결정으로 닫음 — 「미착수」)

---

## 맥락

`CLAUDE.md` §1 은 「6주차 종료 시점에 코어 기준선을 통과하지 못했다면 F·G·H·I 를 착수하지 않는다」고 한다.
통과하면 착수할 **수 있다**는 뜻이지 해야 한다는 뜻은 아니다. 09-22 에 판정용 값(run_id 3·4)이 나와 통과가 유력하지만,
`129` 로 코드 마감이 10-14 다 — 판정일 09-30 부터 **2주**가 남는다.

## 선택지

| | 안 | 판단 |
|---|---|---|
| A | 통과하면 G-2(지역 자원 연계) 착수 | 「폐지·이전 기관 반환 0건」을 우리가 보장할 자원 목록이 없다. 정확도가 높아도 틀린 기관을 안내한다 |
| B | 통과하면 H·I 택1 | 부록 B 모듈은 지표가 아직 6.1절 표에 편입돼 있지 않다. 2주 안에 지표 정의·골든셋·구현·측정을 다 할 수 없다 |
| C | 착수하지 않는다 — 남은 2주는 수동 QA 게이트(`319`) · 시연 결함(절차 고르기·문턱 값) · 여권 조항 · 발표에 쓴다 | ✅ 채택 |

## 결정

**착수하지 않는다.** 09-30 판정이 통과여도 그렇다. 판정문에는 「통과 — 확장은 범위 관리 판단으로 미착수」로 적는다.
F-2 는 `125` 로 이미 구현 완결이라 이 결정의 대상이 아니다.

## 근거

- 09-22 운영 실측에서 시연을 막는 결함이 셋 남아 있다 — 필요서류 절차 고르기(고속버스 문의에 분실물 서류), 「감사합니다」에 조항 5장, 첫 검색 지연. 확장보다 이것이 먼저다.
- 다산콜을 고른 근거인 여권 조항이 아직 지식베이스에 없다 — 차별점의 정답 문서가 없는 채로 확장 모듈을 여는 순서가 아니다.
- 「조건부 항목을 못 한 것은 실패가 아니다」(`w8-extension-pick` 완료 조건). 여유가 없었다고 그대로 적는다.

## 되돌리는 법

09-30 판정 뒤 남은 결함이 다 닫혀 2주가 비면 새 결정 기록으로 연다. 그때 지표를 6.1절 표에 먼저 편입한다.
