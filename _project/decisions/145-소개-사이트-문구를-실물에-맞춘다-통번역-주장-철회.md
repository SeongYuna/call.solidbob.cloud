# 145 — 소개 사이트의 「5개 언어 동시 통번역」 주장을 걷고, 공개 문구를 실물에 맞춘다

- 날짜: 2026-10-01
- 결정자: 정성윤 (사용자 지시 — 10-01 「그 순서로 가자」)
- 관련: `139`(A-5 는 1차 범위만 실물) · `201`(A-5 신설) · `138`(발표 준비 동결 — 시연·발표에 닿는 변경은 지금 한다) · `141`(예시값)

## 맥락

`139` 가 A-5 를 「1차 범위(서툰 한국어 전사)만 실물, 번역·TTS 는 미착수」로 정했는데 **소개 사이트(`www.solidbob.cloud`)가 따라오지 않았다.** Hero 가 「5개 언어 동시 통번역」, 기능 그리드 05 가 「외국인 고객과 5개 언어로 동시 통번역」, 데모 시나리오 목업이 「영어 → 한국어 즉시 번역 · 상담원 답변 → 영어 자막·음성 · 지원 언어 5개」, 개인정보 카드가 「통번역 문장에서 … 가립니다」 라고 적고 있었다. 번역 코드는 0줄이다. 발표장에서 누가 사이트를 열면 바로 어긋난다.

같은 목업에 「관리자 대시보드에 실시간 알림 전송됨」 도 있었다 — 실물은 「관리자 알림 연동 전」(`w6-qa-ui-defects-three` ③).

## 선택지

1. 사이트 문구를 전부 실물로 바꾼다 — 1차 범위(서툰 한국어 전사 + 숙련도별 WER 실측)만 말하고 번역·TTS 는 「미착수(확장)」로 적는다
2. 번역 한 방향(고객 외국어 → 한글)을 먼저 만들고 문구는 그대로 둔다
3. 사이트에서 외국인 응대 항목을 아예 뺀다

## 결정

**1.** 지금 당장. Hero 한 줄 · 기능 그리드 05 · 개인정보 카드 · 데모 시나리오 목업 카드 둘(통번역 · 정서 위기 알림)을 고친다. 목업 카드에는 「목업 — 번역은 구현되지 않았습니다」 를 footer 로 박는다. 수치는 `139` 의 실측값(초급 WER 0.412 · 유창 0.198, 등급당 n 20, 상한)만 쓴다.

**2 는 별도 결정으로 미룬다** — 번역 한 방향을 붙이는 것은 `139` 의 「품질을 잴 표본이 없다」 와 `138` 동결을 함께 뒤집는 일이라, 녹화를 지금 상태로 끝낸 뒤 사용자가 다시 정한다. 붙이더라도 「번역 품질 미측정」 단서는 그대로다.

## 근거

- 절대 원칙 2·10 — 측정하지 않은 것을 된 것처럼 쓰지 않는다. 공개 사이트는 발표 자료와 같은 무게다.
- `139` 가 이미 범위를 정했다. 이 결정은 새 범위가 아니라 **파생물(사이트)을 결정에 맞추는 것**이다(문서 우선순위 §1 — 파생 문서가 결정과 다르면 결정이 맞다).
- 3 은 `201` 의 차별점 구조를 발표 직전에 흔든다. 1차 범위에는 실측값이 있어 보여줄 것이 있다.

## 되돌리는 법

번역이 실제로 붙고 품질이 측정되면 이 문구를 다시 쓴다 — 그때도 「지원 언어 5개」 는 측정된 언어만 적는다.
