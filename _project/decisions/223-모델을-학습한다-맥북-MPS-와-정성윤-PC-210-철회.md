## 맥락

발표 자료를 검토하니 가장 큰 허점이 「**학습을 아예 하지 않고 공개 모델을 그대로 썼다**」 와 「**GPU 가 아예 없다**」 였다.
둘 다 사실과 다르거나 고칠 수 있다.
- **「GPU 가 없다」는 운영 서버(c7i.2xlarge, CPU) 얘기다.** 개발 맥북은 **Apple M5 · GPU 10코어 · 24 GB · PyTorch MPS 사용 가능**(2026-10-15 확인)이고,
  정성윤 님은 집 PC 를 SSH 로 쓴다 — 학습할 장비가 없었던 것이 아니다
- `210` 의 근거였던 「학습할 라벨이 없다」 도 일부만 맞다 — **공개 라벨 데이터**(kocohub 한국어 혐오표현 CC-BY-SA · KLUE NER CC-BY-SA)와
  **생성 학습 데이터**(조항별 질문 doc2query)로 학습하고, 골든셋·외부 데이터로 평가하면 된다(누수 없이)

## 결정

1. **학습한다 — 학습 데이터와 평가 데이터를 가른다.** 골든셋(v1-150.2)은 평가 전용이고 학습에 넣지 않는다. 생성 데이터는 골든셋과 같은 문장을 버린다
2. **맥북(MPS)에서 오늘 하는 것**: ① C-6 폭언 분류기(KcELECTRA 미세조정) ② 조항 검색 임베딩 미세조정(KoE5 · bge-m3) ③ NER 을 KLUE 기반으로 교체 ④ 학습 전후를 같은 하네스로 평가
3. **정성윤 님 PC 로 넘기는 것**(오늘 저녁): 맥북에서 시간·메모리로 못 하는 것만 — STT(Whisper) 도메인 미세조정·GPU 실시간 측정, 리랭커 GPU 지연, 더 큰 학습 반복
4. **운영 배포 기준은 그대로**: 학습한 모델도 같은 하네스에서 지금 모델보다 나아야 올린다. 운영 노드는 CPU 이므로 CPU 지연도 함께 잰다
5. 학습 환경은 운영 의존성과 분리한다(별도 venv) — 서버 이미지에 학습 라이브러리를 넣지 않는다
