# 128. 배포 전 운영 스키마 대조는 릴리스 워크플로가 한다 — 어긋나면 배포를 멈춘다

- 날짜: 2026-09-21
- 작성: 정성윤
- 상태: 채택 — **2026-09-22 구현**(정성윤, `w6-deploy-schema-precheck` — `release.yml` 「운영 스키마를 대조한다」)
- 관련: `decisions/117`(배포는 SSM · OIDC) · `111`·`114`(태그 게이트) · 미결 「운영 스키마가 배포보다 늦게 따라간다」(09-14)
- 티켓: `w6-deploy-schema-precheck`

## 맥락

「머지 = 배포」인데 **스키마 변경은 사람이 운영 DB 에 손으로 넣는다.** 09-14 에 서버 이미지가 마이그레이션보다 먼저 나가
통화 시작 · 필요서류 저장 · 관리자 로그인이 500 이었고 `/health` 는 `ok` 였다. 09-20 에 컬럼 단위 대조 도구
(`scripts/compare_prod_schema.py`)를 만들었지만 **사람이 기억해야 돈다.**

## 선택지

| 후보 | 판단 |
|---|---|
| **릴리스 워크플로가 자동으로 대조한다** | `k3s-deploy` 가 이미 SSM 으로 노드에 들어간다. 같은 길로 서버 파드 안에서 운영 컬럼 목록을 뜨고 대조한다. DB 자격증명이 GitHub 로 나오지 않는다 |
| 런북 19장에 수동 단계로 넣는다 | 코드 변경이 없다. 대신 사람이 잊으면 그대로 샌다 — 원래 문제 그대로다 |
| PR 체크박스(09-16 해결표 20번) | 사람이 「적용했다」고 보고한다. 실제 운영 스키마는 보지 않는다 |

## 결정

**`release.yml` 의 `k3s-deploy` 가 매니페스트를 적용하기 전에 운영 스키마를 대조하고, 어긋나면 적용하지 않고 실패한다.**

- 운영 컬럼 목록은 **SSM 으로 서버 파드 안에서** 뜬다(`compare_prod_schema.py` 머리말 ①의 명령). 스크립트 자체는 DB 에 접속하지 않고 텍스트 두 개만 비교한다
- 비교 대상은 **이번에 배포할 커밋의 `db/schema.sql`** 이다
- 🔴(양쪽에 있는데 다르다)·🟡(`schema.sql` 에만 있다)이면 **멈춘다.** 🟡(운영에만 있다)은 경고로 남기고 진행할지 구현 때 정한다
- 워크플로 로그에 **연결 문자열·값을 찍지 않는다**(SEC-2). 컬럼 이름과 타입만 나온다

**운영 순서가 이렇게 바뀐다**: 마이그레이션이 든 PR 을 머지하면 배포가 **일부러 실패한다** → 사람이 운영 DB 에 마이그레이션을 넣는다 →
워크플로를 다시 돌린다 → 대조가 통과하고 배포된다. 실패가 곧 「마이그레이션을 넣으라」는 알림이다.

## 근거

- 문제의 원인이 「사람이 기억해야 돈다」였다. 수동 단계나 체크박스는 그 원인을 그대로 둔다
- SSM 경로는 이미 배포가 쓰고 있어 새 자격증명·새 권한이 들지 않는다(`117`)

## 되돌리는 법

`release.yml` 의 대조 단계를 지운다. 대조 스크립트와 런북 절차는 그대로 남는다.

## 구현 (2026-09-22, 정성윤)

- 위치: `release.yml` `k3s-deploy` — 「인스턴스가 켜져 있는지 본다」 뒤, 「SSM 으로 적용한다」 **앞**. 실패하면 `apply` 가 건너뛰어지고 되돌리기 단계(`apply` 실패일 때만)도 돌지 않는다 — 운영은 그대로다
- **🟡 운영에만 있음은 경고로 정했다**(`--allow-prod-extra`) — 지금 코드를 깨지 않는다. 손으로 돌릴 때(기본)는 여전히 어긋남으로 센다
- 덤프가 잘리면(SSM 24,000자) 머리말 `ROWS n` 과 실제 행 수가 달라 **판정하지 않고 멈춘다.** 서버 배포가 아직 없는 새 클러스터면 건너뛴다(notice)
- 검증: 스크립트 테스트 5건(같음 통과 · 마이그레이션 미적용 멈춤 · 타입 차이 멈춤 · 운영에만 있음 경고 · 잘린 덤프 멈춤) · **이 머신에서 워크플로 단계를 그대로 운영에 돌려 봤다** — 운영에 `eval_run.components`(PR #132, `2026-09-22-eval-run-components.sql`)가 빠져 있어 **멈췄다.** 붙이자마자 실제 누락을 하나 잡은 셈이다. 그 마이그레이션을 넣고 나서 머지한다
