#### `f = 0.635` 를 고른 방법 (학습 표본에서)

09-22 16:43 로컬 E2E(v0 24건, `callguard_e2e` DB 의 `recommendation`·`recommendation_card` rank 1)에서, 필요서류 대본마다

3. (i) **그리고** (ii) 를 넘은 것은 C2 하나뿐이므로 「가장 적은 것」·「같으면 단순한 쪽」을 따질 것이 없다.

## 아직 열려 있는 것

- **남은 3쌍은 줄이지 못했다.** SYN-108 은 「세대주가 뭐예요?」 같은 되묻기의 1순위가 3.8·3.10(세대분할·전입) 로 가고 점수도 하한 위다 — **내용 있는 발화의 오답 1순위**라 점수로 못 거른다. SYN-109 는 시 소관이 아닌 민원인데 2.7(알뜰교통카드)이 하한을 넘는다. 이건 채택 조건이 아니라 **검색 쪽(B-2/B-3) 문제**다.
- **누적은 그대로다.** 한 번 잡힌 절차는 내려가지 않아 상담원 발화마다 다시 판정된다(엉뚱한 «행»이 «쌍»의 4배인 이유). **새 절차가 잡히면 이전 절차를 내리는 동작은 화면(`apps/call`, 조서희 님)과 함께 정해야 해서 이번 후보에서 뺐다** — 티켓 `w6-procedure-noise-redesign` 의 범위 밖으로 남긴다.
- **`source: synthetic` 상한이다.** 글자를 직접 흘려 STT 를 거치지 않았다 — 실제 통화의 재현율이 아니다(절대 원칙 2·10).
- **보류 표본을 이번에 썼다.** `dasan-v1-holdout` 12건은 이제 «본 표본»이다. 다음 후보는 또 다른 새 표본으로 잰다.
- ⚠ **엄밀히는 「한 번」이 아니다 — 09-22 에 보류 표본으로 C0·C1·C2 를 이미 한 번 보았다**(`data/processed/qa-2026-09-22/n2/reports/c0-holdout/2026-09-22-1752.md` 등, gitignore). 09-24 의 C0 이 그때와 글자 하나 다르지 않은 것도 그 기록과 대조해서 안 것이다. **다만 후보 값(`f = 0.635`)·어휘·규칙은 학습 표본 v0 에서만 골랐고**(사전 등록 커밋 `f088e3e`) 09-22 결과를 보고 고치지 않았다 — 사전 등록의 취지는 지켜졌다. 그래도 **보류 표본의 「처음 보는 눈」은 09-22 에 이미 썼다는 것**을 숨기지 않고 적는다(절대 원칙 8).
