# 121. 모델은 전용 GPU EC2 에 올린다 — 서버 파드(t3.large)에는 싣지 않는다

- 날짜: 2026-09-21
- 작성: 정성윤
- 상태: 채택(방침) — **인스턴스는 아직 없다.** 만들 때까지 운영은 규칙 + BM25 그대로다
- 관련: `decisions/208`(류준 — NER·임베딩을 지금 노드에 먼저 켜자는 제안) · `206`(dense+리랭커 채택) · `207`(생성 모델) ·
  `024`·`105`(`ai/` 는 라이브러리 · 한 컨테이너) · `116`(자동 중지를 하지 않는다 — **t3.large 전제**) · 런북 0장·부록 A-1
- 티켓: 없음(인스턴스를 만들 때 연다)

---

## 맥락

`decisions/208` 은 운영 노드(`t3.large` · 메모리 7.8GB 중 3.6GB 사용)에 **NER 과 임베딩을 먼저 올리고 리랭커는 GPU 뒤로 미루자**고 제안했다.
근거는 둘이었다 — ① 이름·번지가 원문으로 남는다(SEC-1) ② 필요서류 판정이 BM25 1순위 오답에 끌려간다.

그 뒤 사정이 바뀌었다.

- **①은 규칙 보강으로 골든셋 기준 해소됐다.** `server:0.1.18` 이 운영에 떠 있고, **그 규칙만으로** 골든셋 `v1-150` 의 C-5 36건이
  전부 통과한다(2026-09-19~20 확인 — 서버 골든 테스트 73 · 하네스 `--no-ner` 누락 0 · n 28). 남은 것은 규칙이 원리상 못 잡는
  「호칭·문맥 없는 이름」이다.
- **②는 여전하다.** 검색 Recall@5 가 운영(BM25) 0.833, 모델 구성 0.979 로 갈린다.
- 노드에 2~3GB 를 더 얹으면 여유가 거의 없고, 리랭커(3.3GB · p50 433ms)는 CPU 에서 4.3절 예산을 먹는다.

## 결정

**모델(NER · 임베딩 · 리랭커 · 생성)은 전용 GPU EC2 를 따로 세워 거기에 올린다.**
`t3.large` 서버 파드에는 torch·모델 파일을 넣지 않는다 — 서버 이미지는 지금처럼 가볍게 둔다.

`208` 의 「NER·임베딩을 지금 노드에 먼저」는 **채택하지 않는다.** 「리랭커는 GPU 뒤로」는 이 결정과 같은 방향이다.

## 이 결정이 함께 여는 질문 — 아직 정하지 않았다

숨기지 않고 적는다. 인스턴스를 만들기 전에 답해야 한다.

1. **`ai/` 가 「라이브러리」에서 「서비스」가 된다.** `024`·`105` 는 `ai/` 를 서버와 **같은 프로세스**에 싣는 라이브러리로 정했다.
   모델이 다른 머신에 있으면 **HTTP(또는 gRPC) 표면**이 필요하다. 포트(`RetrievalPort`·`MaskingPort` 등)는 그대로 두고
   **어댑터만 원격 호출로 바꾸면 되는 구조**이긴 하다 — 다만 `ai/requirements.txt` 에 웹 프레임워크가 없다는 `024` 의 전제가 깨진다.
2. **런북 부록 A-1(「서버와 GPU 를 분리하지 않는다」)과 반대다.** 그 근거는 네트워크 홉 지연이었다.
   분리하면 검색·마스킹마다 홉이 하나 더 붙는다 — **4.3절 예산(내부 처리 p95 ≤ 1,000ms)에 그 몫을 더해 다시 재야 한다.**
   특히 **C-5 마스킹은 자막·저장의 앞단**이라, NER 을 원격으로 부르면 모든 발화가 그 왕복을 기다린다.
3. **비용과 자동 중지.** 런북 0장의 경고(`g4dn.xlarge` 24/7 = 약 $597, 예산 초과)가 **이 인스턴스에는 그대로 적용된다.**
   `116` ①(자동 중지를 하지 않는다)은 **`t3.large` 를 전제로 한 결정**이라 GPU 인스턴스에는 옮겨 가지 않는다 — 그쪽은 자동 중지가 다시 필요하다.
4. **GPU 가 꺼져 있을 때의 동작.** 지금 설계(모델이 없으면 규칙·BM25 로 조용히 내려간다)를 **원격이 안 붙을 때에도 똑같이** 지켜야 한다.
   GPU 가 꺼졌다고 자막·마스킹이 멈추면 안 된다.
5. **6주차 판정(09-30)의 기준선 구성.** 판정일까지 GPU 인스턴스가 떠서 운영 경로에 붙어 있으면 **모델 구성**을,
   아니면 **운영 구성(규칙 + BM25)**을 기준선으로 삼고 모델 구성은 **로컬 측정 참고치**로 나란히 적는다.
   **떠 있지 않은 구성의 수치로 「통과」를 선언하지 않는다.**

## 되돌리는 법

인스턴스를 만들지 않으면 아무것도 바뀌지 않는다 — 운영은 규칙 + BM25 로 계속 돈다.
`208` 로 돌아가려면(지금 노드에 NER·임베딩) 서버 이미지에 torch CPU 휠을 넣고 모델 볼륨을 붙인다.
