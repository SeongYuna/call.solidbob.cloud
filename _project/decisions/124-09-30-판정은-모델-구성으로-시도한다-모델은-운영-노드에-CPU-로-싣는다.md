## 맥락

- 성공 조건 둘(STT 오류 내성 · 검색 품질) 중 검색은 **모델 구성에서만** 0.979 다. 운영(BM25)은 0.833 이고 오류 20% 에서 0.792 로 내려간다.
  C-5 도 규칙만으로는 STT 오류 5% 에서 2건 뚫리고, 규칙+NER 은 10% 까지 0 이다. **둘 다 모델이 운영 경로에 붙어야 운영 수치가 된다.**
- 운영 노드 실측(09-22, SSM): `t3.large` 1대, 메모리 7.8 GB 중 **여유 4.5 GB**, 디스크 30 GB 중 19 GB 여유, 서버 파드 상한 **1 Gi**. GPU 없음.
- 모델 파일은 류준 님 맥에만 있다. S3 `models/` 는 비어 있다(09-22 실측).
- 사용자(정성윤)가 2026-09-22 에 「모델 구성으로 시도」를 골랐다.

## 결정

**B 로 간다.** 리랭커는 싣지 않는다 — 로컬 측정에서 Recall@5 를 한 건도 더 못 맞히고 MRR 만 0.034 올리므로, 노드 증설과 서버 정지를 감수할 값이 아니다. 판정 뒤 여유가 있으면 C 로 올린다.

순서(셋째 판 「모델 계획」을 B 로 좁힌 것). **앞이 안 되면 뒤를 하지 않는다.**

1. **류준 님이 모델 두 폴더를 S3 에 올린다** — `s3://assist-apne2/models/koelectra-ner/` · `s3://assist-apne2/models/koe5/`. 로컬 측정에 쓴 바로 그 폴더(해시를 티켓에 적는다). 리랭커는 생략.
2. **저장소 변경 한 PR** — 서버 이미지에 torch CPU 휠(`ai/requirements.txt` 의 torch 를 서버 Dockerfile 에서 CPU 인덱스로), 서버 파드에 모델 볼륨(hostPath `/opt/callguard/models`)과 메모리 상한 **1 Gi → 3 Gi**, 서버 태그 올림, 런북 11장(GPU 원안)을 「운영은 CPU, 이 결정」으로 정정.
3. **노드로 모델을 받는다** — SSM 으로 `aws s3 sync s3://assist-apne2/models /opt/callguard/models`. 디스크 여유를 먼저 본다.
4. **검색 인덱스에 벡터를 다시 넣는다** — 운영 ES 는 BM25 만 적재돼 있어 **벡터 없는 인덱스에서 dense 검색은 0건**이다(`scripts/index_knowledge_base.py` 머리말). 새 이미지가 뜬 뒤 서버 파드 안에서 `--to-es --recreate`. ⚠ **임베딩을 켜기 전에** 한다. `DASAN-POLICY-1` 문구가 09-21 에 바뀌었으니 재색인 뒤 골든셋 Recall 이 달라질 수 있다 — 값은 그대로 적는다.
5. **하나씩 켠다** — `server-env` 백업 → `PII_NER_MODEL_DIR` → 재시작 → `/health` `spokes` 에 `pii_ner` → `RETRIEVAL_EMBED_MODEL_DIR` → 재시작 → `embedding`. 경로가 틀려도 서버는 에러 없이 규칙만으로 뜨므로 **`spokes` 를 봐야 성공을 안다.** 메모리·재시작 횟수를 같이 본다.
6. **검증** — 합성 통화 1건(SYN-010, 사용자 허용 09-22)으로 검색 구간 시간 · 이름만 넣은 발화가 가려지는지. 내부 처리 p95 가 1,000 ms 를 넘으면 임베딩만 끄고 운영 구성으로 판정한다.
7. **판정 전 측정** — 류준 님이 `run_eval.py --runs 3 --record` 를 운영 구성 옆에 나란히. 실행 ID 없는 값은 기준선으로 쓰지 않는다(§5).

## 근거

- `121` §5 가 이미 「붙어 있으면 모델, 아니면 운영」을 정해 뒀다. 이 결정은 **붙이려는 시도를 승인**하는 것이지 판정 규칙을 바꾸는 것이 아니다. 시도가 실패해도 판정은 성립한다.
- 노드 여유 4.5 GB 에 2.3 GB 는 들어간다. 3.3 GB 는 ES(2 GB 안팎)·미디에이터·redis 와 겹쳐 빠듯하다.
- 원격 어댑터를 안 만드니 `024`·`105`(ai 는 라이브러리)가 그대로 산다. `121` 이 열었던 질문 1·2·4 가 사라진다.
- 비용 증가 0 (같은 노드).

## 되돌리는 법

- 5단계에서 `server-env` 백업을 되살리고 재시작하면 즉시 운영 구성으로 돌아간다(모델 키 두 개만 빠진다).
- 4단계 재색인은 되돌릴 수 없다 — 벡터가 있는 인덱스는 BM25 에도 무해하므로 되돌릴 필요가 없다.
- 09-30 까지 못 붙이면 이 결정은 「시도했으나 미달」로 남기고 `121` §5 규칙대로 운영 구성으로 판정한다. 결정 파일은 지우지 않는다(절대 원칙 8).
