## 사전 등록 (측정 전에 적었다 — 아래 값은 결과를 보고 바꾸지 않는다)

**후보는 하나로 얼렸다.**

- 규칙: **dense(KoE5 kNN) 검색이 결과를 낸 경우에만**, 1순위 점수 `score < 0.67` 이면 카드 0장(기권).
  점수는 ES `similarity: cosine` 의 `_score` = `(1 + cos) / 2` — `scripts/measure_no_answer_threshold.py` 가 잰 것과 같은 눈금.
- BM25 단독 구성에는 걸지 않는다(눈금이 다르다 — raw `_score`, 상한 없음).
- 값의 출처: 09-21·09-22 측정에서 GS-701~724 24건 + B 96건으로 본 「정답 1건 잃는 t = 0.671」. **같은 표본으로 고른 값이라 그 표본으로는 채택 근거가 되지 않는다.**

**새 케이스(고르는 데 안 쓴 것)를 먼저 쓰고, 점수를 보지 않고 쓴다.**

- 파일: `golden-set/b6-holdout-2026-09-22.json` — **공식 골든셋 `v1-150.json` 에 넣지 않는다**(09-30 판정 전, `decisions/123`).
- 약 24건, GS-701~724 와 같은 모양(`module: "B-6"`, `expected_doc_ids: []`), 유형 비율도 비슷하게 — 타 기관 소관 · 시 범위 밖 · 잡담/맞장구(「아 네, 알겠습니다」·「감사합니다」 포함) · 지식베이스 공백.
- 각 항목은 `knowledge-base/dasan/` 를 grep 해 답하는 조항이 없는 것만.

**한 번 잰다.** `scripts/measure_no_answer_threshold.py` 로 로컬 인덱스 `callguard-kb-single`(읽기 전용) · KoE5 에서 t = 0.67 의

- ① 새 케이스 걸러냄 x / n
- ② 정답 있음 손실 — B 96건 중 **dense 상위 5 에 정답이 든 항목**이 1순위 점수 < 0.67 로 기권해 정답을 잃는 수(09-21·09-22 표의 「정답 잃음」과 같은 정의). **이 96건은 재사용 표본이다** — 값을 고를 때 쓴 것이다.

**채택 규칙:** ① ≥ 50 %(24건이면 12건 이상) **그리고** ② ≤ 1 이면 채택. 아니면 **넣지 않는다**(숫자와 함께 기록). 결과를 본 뒤 t 를 다시 고르지 않는다.

**채택되면 적용 위치:** `FallbackRetriever` — dense 가 문서를 냈는데 1순위 < t 면 **빈 결과를 돌려주고 BM25 로 내려가지 않는다**(내려가면 BM25 가 카드 5장을 다시 채워 문턱이 무의미해진다). dense 가 0건(벡터 없음·실패)이면 오늘처럼 BM25 로 내려간다.
