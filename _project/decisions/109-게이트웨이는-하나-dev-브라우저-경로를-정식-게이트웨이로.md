# 109 — 게이트웨이는 하나다. `/dev` 브라우저 음성 경로를 정식 게이트웨이로 옮긴다

**날짜**: 2026-09-11
**작성**: 정성윤 (브랜치 `PM`)
**관련**: `decisions/402`(조서희 — frontend 브랜치, 이 기록이 일부를 대체한다) · `decisions/105`(한 컨테이너·한 도메인) ·
`decisions/302`(담당 잠금 해제) · [w4-gateway-streaming-stt](/backlog/w4-gateway-streaming-stt/) ·
[w4-gateway-dev-browser-stt](/backlog/w4-gateway-dev-browser-stt/) · [w3-gateway-dev-testcall](/backlog/w3-gateway-dev-testcall/)

## 맥락

같은 날 `services/gateway` 에 **게이트웨이가 둘** 생겼다. 서로 몰랐다.

| | 조서희 (frontend 브랜치, `402`) | 정성윤 (main, 배포됨) |
|---|---|---|
| 무엇 | 개발용 배선 확인 — 브라우저 음성 인식(Web Speech API)이 글자를 보낸다 | 정식 A-1 — 오디오를 서버에서 Google STT 로 전사 |
| 스스로 적은 범위 | «정식 A-1/A-2 는 여전히 미착수, 품질 측정용 아님» | A-1~A-4 · COST-1 · 접속 제어 |
| 형태 | Express · `server.js` 등 JS · 대시보드 `/dashboard` · 인증 없음 | `node:http` · TS · 대시보드 `/ws` · 문마다 토큰 · k8s 배포 |

**기능은 겹치지 않는데 자리가 겹친다.** 그대로 합치면 `README`·`package.json`·락파일이 충돌하고, 한 디렉터리에 서버가
둘이 되며, 조서희 쪽 `src/` 가 들어오는 순간 이미지 태그 검사(`release.yml`)가 릴리스를 막는다.

`CLAUDE.md` §4 는 «같은 티켓을 두 사람이 다르게 고치면 먼저 손댄 쪽을 살린다» 고 한다. 착수는 조서희가 먼저다(09-10 지시).
그러나 **티켓도 범위도 다르다** — 402 는 스스로 정식 A-1 이 아니라고 적었고, 정식 쪽은 이미 main 에 들어가 운영에 떠 있다.

## 선택지

| | 방법 | 문제 |
|---|---|---|
| A | 402 쪽을 살리고 정식 게이트웨이를 되돌린다 | 운영에 뜬 정식 A-1(STT·COST-1·인증)을 버리고, A-1 은 다시 0줄이 된다 |
| B | 둘 다 두되 디렉터리를 가른다(`services/gateway-dev/`) | 같은 일(허브 호출·대시보드 중계·마스킹 실패 처리)을 두 벌 유지한다. 인증 없는 쪽이 운영 도메인에 붙을 여지가 남는다 |
| C | **정식 게이트웨이 하나로 두고, 402 의 쓸모를 입력 방식 하나로 옮긴다** | 옮기는 작업이 든다 |

## 결정

**C.**

1. `services/gateway` 는 **하나**다 — 정식 게이트웨이(main)가 기준이다.
2. 402 의 `/dev`(브라우저 음성 인식 → 글자)를 **글자 입력 채널**로 옮긴다 — `GET /dev` · `WS /dev/text`.
   같은 파이프라인(서버 마스킹 → 대시보드)을 탄다. 통화 기록 엔진은 사실대로 `web-speech`. 구글을 부르지 않으므로 COST-1 캡과 무관하다.
3. 글자 입력 문은 **DB 에 전사를 쓰므로 과금 문과 같은 비밀 토큰**(`GATEWAY_INGEST_TOKEN`)을 요구한다. 브라우저는 서브프로토콜로 낸다.
   뷰 토큰(공개 번들에 들어갈 수 있는 값)으로는 열리지 않는다.
4. **프록시 헤더가 붙은 루프백 요청은 «이 머신» 으로 치지 않는다.** 402 의 흐름은 ngrok 을 쓴다 — 터널은 인터넷 요청을 루프백으로
   넘기므로, 이걸 안 막으면 터널 한 줄로 문이 열린다.
5. 402 의 대시보드 경로 `/dashboard` 를 `/ws` 별칭으로 받는다 — 그 안내대로 붙인 대시보드가 그대로 붙는다.
6. 402 의 **대시보드 런타임 주소 덮어쓰기(`?gateway=`, `apps/dashboard/src/lib/ws/types.ts`)는 그대로 살린다** — `apps/` 는
   조서희 전담(`302`)이라 이 기록이 건드리지 않는다. 정식 게이트웨이와도 맞물린다.
7. frontend 브랜치를 main 에 합칠 때 **`services/gateway` 는 main 쪽을 쓰고 frontend 쪽 것은 버린다.** 402 는 «일부 대체됨(109)» 으로 표시한다.
   할 일은 [미결](/open-items/)에 조서희 님께 남긴다 — 남의 브랜치를 이 기록이 고치지 않는다.

**`105` 와의 관계** — 105 는 server 와 `ai/`(둘 다 파이썬)를 한 컨테이너로 묶은 결정이고 게이트웨이는 그때 없었다. 게이트웨이는
런타임이 다른 Node 라 **컨테이너는 따로**(런북 0장이 이미 «Node 게이트웨이» 를 같은 노드에 넣고 계산했다), **도메인은 105 대로 하나**다 —
`server.solidbob.cloud/gateway`.

## 근거

- **A 는 되돌리는 쪽이 운영이다.** 402 가 스스로 «정식 A-1 아님» 이라 적었으므로, A 를 고르면 「필수」 블록이 다시 비는 대신 얻는 것이 없다.
- **B 는 두 벌이 갈라진다.** 마스킹 실패 처리(SEC-1)·허브 호출 순서(`/hub/calls` 먼저) 같은 규칙을 두 곳에서 지켜야 한다. 이 저장소는
  이미 두 사람이 같은 것을 두 번 만든 이력이 여러 번 있다(`STATE.md` 내부 메모).
- **C 는 402 의 쓸모를 하나도 잃지 않는다** — 키 없이 폰으로 테스트하는 것(운영 `https://server.solidbob.cloud/gateway/dev` 는 이미 HTTPS 라
  ngrok 도 필요 없어졌다), `?gateway=` 덮어쓰기, `/dashboard` 경로.

## 되돌리는 법

- `/dev` 를 없애려면 `ws_server.ts` 의 `ROUTES` 에서 `/dev/text` 를, `handleHttp` 에서 `/dev` 를 지우고 태그를 올린다. 글자 채널(`source: "text"`)은
  남겨도 해가 없다.
- 402 쪽을 다시 살리려면 frontend 브랜치의 `services/gateway` 를 `services/gateway-dev/` 로 옮겨 합친다(선택지 B).
