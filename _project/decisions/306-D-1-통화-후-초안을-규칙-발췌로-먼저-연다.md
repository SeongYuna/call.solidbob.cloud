# 306 — D-1~D-3 통화 후 초안을 LLM 없이 규칙 발췌로 먼저 연다

**날짜**: 2026-09-15
**작성**: 장민석 (브랜치 `server`)
**관련**: 티켓 `w7-postcall-contract`(계약·501) · `w7-postcall-spoke`(류준, LLM 요약) · `w7-postcall-persistence` · 절대 원칙 9·10 · 부록 A-1

## 맥락

`POST /hub/calls/{call_id}/close` 는 계약·배선만 있고 **501** 이었다(`postcall` 스포크 없음). 프론트 통화 후 화면을 붙이면
「미구현」만 보인다. 요약을 만들 LLM(런북 14장 Ollama + EXAONE)은 **운영에 떠 있지 않다** — 운영 k3s 에는 server·gateway·ES 뿐이다.

## 선택지

| | 내용 | 걸리는 것 |
|---|---|---|
| ① **규칙 발췌 초안** | 마스킹된 확정 발화에서 문장을 **골라 붙인다.** 인프라 추가 없음 | 요약이 «문장을 쓰지» 않는다 — 발췌다 |
| ② LLM 요약 | `ai/` 에 Ollama 어댑터 | GPU·Ollama 배포(정성윤) 전까지 로컬 전용 |
| ③ 보류 | 7주차 일정대로 | 501 유지 |

## 결정 (사용자 선택, 2026-09-15)

**①로 먼저 연다. ②는 나중에 같은 포트 뒤에 들어올 수 있다.**

- 위치: **`server/apps/postcall/`** — 규칙 기반이라 요청 경로 쪽이다(`server/CLAUDE.md` §0, `docs/architecture.md` §1 표가 이미 `postcall` 을 `server/` 로 적었다).
  판정 규칙은 `domain/services/summary_rules.py`(표준 라이브러리만), 허브와 잇는 것은 `adapter/outbound/rule_postcall_adapter.py`
- `hub/dependencies/postcall_provider.py` 기본값이 규칙 어댑터다 — `masking`·`closure_gate` 와 같은 방식. `/health` `spokes` 에 `postcall` 이 뜬다
- **D-1 요약**: 고객의 첫 «실질» 발화(공백 뺀 8자 이상) + 그 뒤 상담원의 첫 실질 발화 + 발화 건수 + `(규칙 발췌 초안)` 표시
- **D-2 유형**: **`null`.** 유형을 가를 규칙표가 없다 — 없는 규칙으로 분류하면 지어낸 값이다(절대 원칙 10)
- **D-3 후속조치**: 상담원 발화 중 「…드리겠습니다/드릴게요」 약속 어미 **와** 통화 뒤에 남는 동사(연락·회신·문자·발송·보내·접수·전달·연결·처리·확인해)가 함께 있는 것. 200자(`follow_up_action.action_text`)로 자른다
- 인터랙터·계약은 손대지 않았다 — `confirmed` 는 여전히 서버가 `false` 로 덮는다

## 근거

- **발췌는 환각이 없다.** 화면에 나가는 글자는 전부 자막 어딘가에 있다(테스트가 고정한다). LLM 이 들어와도 이 성질을 가진 폴백이 남는다
- 빈 요약·「요약 없음」을 내지 않는다 — 발췌할 발화가 없어도 건수는 사실이다. 501 을 없앤 대가로 «모듈이 없는 것» 과 «내용이 없는 것» 이 섞이지 않게 했다
- 인프라를 늘리지 않는다 — 운영에 Ollama 가 없는 지금 ②는 배포할 수 없다

## ⚠ 남는 것 — 주장 범위

- **품질을 잰 적이 없다.** 골든셋 D 케이스 0건. 요약 품질·D-3 재현율을 수치로 말하지 않는다
- «실질» 발화를 길이로만 가른다 — 짧은 핵심 발화(「카드 분실요」)를 놓칠 수 있다
- D-3 은 어휘 규칙이라 부정(「연락 안 드리겠습니다」)도 잡는다 — 초안이고 상담원이 지운다
- **저장하지 않는다** — `call.summary_text`·`follow_up_action` 저장은 `w7-postcall-persistence` 로 남는다
- LLM 요약(`w7-postcall-spoke`, 류준)은 그대로 남는다 — 들어오면 프로바이더 한 줄을 바꾸고, 이 어댑터는 폴백으로 둘지 정한다

## 되돌리는 법

1. `hub/dependencies/postcall_provider.py` 의 `get_postcall_port` 를 다시 501 을 올리게 바꾼다
2. `main.py` `_BUILTIN_SPOKES` 에서 `"postcall"` 을 뺀다 · `server/apps/postcall/` 를 지운다 · `.importlinter` 의 `postcall` 5곳을 지운다
3. `tests/test_main_health.py`·`test_postcall_router.py` 를 501 기대값으로 되돌린다
