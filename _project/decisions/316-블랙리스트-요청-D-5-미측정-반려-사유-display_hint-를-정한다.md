# 316 — 블랙리스트 요청: D-5 는 「미측정」으로 · 반려 사유는 필수로 · `display_hint` 는 채우지 않는다

**날짜**: 2026-09-22
**작성**: 장민석 (브랜치 `server`)
**관련**: `decisions/203`(D-5 통화 온도) · `204`·`205`(J 블록) · `304`(HMAC 고객 식별) · `312`(180일 보존) · 절대 원칙 3·8·10 · 티켓 `w7-d5-server-wiring` · `w7-blacklist-leftovers`

## 맥락 — 셋 다 `blacklist_request` 한 테이블이다

1. **D-5 온도 이상이 늘 0 이었다.** `voice_outlier` 에 쓰는 곳이 서버 요청 경로에 없다(09-22 전수 확인 — 포트·저장소는 있으나 부르는 것은 `ai/` 평가 쪽뿐).
   근거 수집은 그 테이블을 세므로 늘 0 이고, 관리자는 근거 화면의 0 을 「이상 없음」으로 읽는다. D-5 는 음성 톤이라 전사만 받는 서버로는 못 만든다 — 오디오는 콜 미디에이터에 있다
2. **반려 사유가 어디에도 남지 않았다.** 결정의 `note` 는 승인일 때만 등록(`blacklist_entry.note`)에 저장되고 반려면 버려졌다
3. **`display_hint`(관리자가 고객을 알아볼 단서)를 채우는 경로가 없다.** 식별자가 HMAC 이라 비어 있으면 목록이 해시뿐이다

## 결정

1. **`temperature_outliers` 를 NULL 허용으로 — NULL = 「미측정」**. 근거 수집 저장소가 `voice_outliers_wired` 로 판정 배선 여부를 받고, 지금은 `False` 라 NULL 을 낸다.
   응답도 `null`. 판정이 붙으면(콜 미디에이터가 오디오로 판정해 `voice_outlier` 를 채우면) 프로바이더 한 줄을 `True` 로 바꾼다.
   **지금까지 저장된 0 은 소급해 바꾸지 않는다**(절대 원칙 8 — 그때 화면에 그렇게 보였다)
2. **반려에는 사유가 필요하다**(없으면 422). 마스킹해 새 컬럼 `blacklist_request.decision_note` 에 둔다. 승인 메모는 전처럼 등록 쪽 — **한 벌만** 남긴다.
   `312` 의 180일 정리에 반려 사유도 넣었다(반려 요청의 사유·자막과 같은 이유)
3. **`display_hint` 는 채우지 않는다.** 전화번호 뒷자리도 P4 의 일부라, 넣는 순간 HMAC 으로 가린 것을 되돌리는 단서가 된다. 애매하면 넣지 않는다(재현율 우선과 같은 방향).
   관리자는 `call_id`·마스킹된 자막 발췌로 알아본다. 컬럼은 되돌릴 때를 위해 남기고 응답은 늘 `null`
4. 연장 이력 조회(`GET …/expiry-changes`)는 서버에 이미 있다 — 화면만 남았다(조서희 님)

스키마: `db/migrations/2026-09-22-blacklist-request-note-unmeasured.sql`(순증, 29 테이블 그대로). **서버 이미지보다 먼저 넣는다.**

## 근거

- 0 과 「안 쟀다」를 같은 값으로 두면 측정하지 않은 것을 측정한 것처럼 보인다(절대 원칙 10)
- 반려된 쪽이 이유를 모르면 같은 요청이 반복된다. 조치 대상이 아닌 사람의 기록이 늘어나므로 보존 정리에 같이 넣는다

## ⚠ 남는 것

- **요청한 상담원이 반려 사유를 볼 경로가 아직 없다** — 상담원용 「내 요청」 조회 API·화면이 없다. 지금은 관리자 화면에만 보인다
- 프론트: 관리자 반려 버튼이 사유를 받아야 한다(없으면 422) · `temperature_outliers` `null` 을 「미측정」으로 보여야 한다(`toNum(null)` 이 0 이 되면 안 된다) — 조서희 님
- D-5 의 실제 배선(미디에이터 오디오 → 판정 → `voice_outlier`)은 음성 골든셋이 없어 판정 품질을 잴 수 없다 — 붙여도 수치는 「측정 불가」다

## 되돌리는 법

①은 프로바이더를 `True` 로(판정이 붙었을 때), 컬럼을 되돌리려면 NULL 행을 0 으로 채운 뒤 `SET NOT NULL`. ②는 인터랙터의 필수 검사를 걷는다(컬럼은 남겨도 된다). ③은 채우는 코드를 넣으면 된다 — 무엇을 넣을지부터 다시 정한다.
