# 313 — J-5 베테랑 배정을 «인입 전 판정 API» 로 열고, 근속 기준을 관리자 설정으로 저장한다

**날짜**: 2026-09-15
**작성**: 장민석 (브랜치 `server`)
**관련**: `decisions/204`(J-5 — 인입 시 베테랑 배정, 「얇은 필터」) · 미결 「베테랑 기준 3년의 근거가 없다」 · 「J-5 배정은 인입 경로에 아직 안 붙었다」 · 관리자 설정 탭(조서희 — 「서버에 연결 안 됨」)

## 맥락

배정 규칙(`blacklist/domain/services/routing.py` `route()`)과 기록 테이블(`routing_log`)은 09-09 부터 있었지만 **아무도 부르지 않았다.**
관리자 화면에 「근속 연차」 설정이 있는데 저장할 곳이 없었다. 막힌 것이 둘이었다 —

1. **부를 자리가 없다.** 실제 연결은 교환기(ACD)가 하고 우리에게 교환기가 없다. `POST /hub/calls` 는 게이트웨이가 상담원과 **이미 연결된 뒤** 부른다 — 거기서 배정하면 늦다
2. **후보 상담사를 모른다.** 규칙은 «지금 받을 수 있는» 상담사를 받는데 서버에 대기 상태 정보가 없다

## 결정 (사용자 선택, 2026-09-15)

| | 선택 | 대안 |
|---|---|---|
| 시점 | **인입 전 배정 판정 API** | 통화 시작 때 판정해 기록만 |
| 후보 | **요청에 후보 명단을 받는다** | agent 전원을 후보로 |

- `POST /hub/routing-decisions {call_id, candidates[]}` — 순서는 **`POST /hub/calls`(발신 번호 → 고객 식별) → 판정 → 부르는 쪽이 연결**. 발신 번호를 다시 받지 않고 통화의 `customer_id` 를 쓴다
  - 블랙리스트 여부: 그 고객에 **적용 중** 등록이 있는가 · 근속: `agent.hired_on` → 지금(365.25일=1년), 입사일 없으면 0년 · 후보 중 `agent` 에 없는 ID 는 빼고 `unknown_candidates` 로 돌려준다
  - 판정은 **블랙리스트 도메인 `route()`** 가 한다 — 허브·어댑터에는 근속 if 가 없다. 결과는 **`routing_log` 에 남는다**(블랙리스트 아닌 통화도)
  - **`call.agent_id` 는 건드리지 않는다** — 판정이지 실제 수신 상담사가 아니다
  - 인증 없음 — 통화 시작과 같은 수준(부르는 쪽은 교환기·게이트웨이). 통화 없음 404 · DB 없음 501(블랙리스트 여부를 모르고 배정하면 J-5 가 아니다)
- `GET·PUT /hub/routing-settings {veteran_years}`(관리자) — 새 테이블 **`app_setting`**(키-값). 0.5~40년. **저장값이 없으면 도메인 기본값 3년** 을 `saved: "false"` 로 — 기본값을 DB 에 미리 넣지 않는다(두 곳에 적지 않는다). 바꾼 관리자를 `updated_by` 로 남긴다

## 근거

- 배정은 연결 **전** 결정이어야 의미가 있다 — 통화 시작 시점 판정은 «배정됐어야 할 상담사» 기록일 뿐이다
- 대기 상태를 서버가 지어내면(전원 후보) 통화 중·휴식 중 상담사가 뽑혀 결과가 틀린다. 아는 쪽이 준다
- 설정을 서버에 두어야 판정과 화면이 같은 값을 본다. 204 가 «코드에 굳히지 않고 설정으로 뺀다» 고 적어 둔 것을 실제로 연다

## ⚠ 남는 것

- **부르는 곳이 아직 없다** — 교환기가 없고 게이트웨이도 부르지 않는다. 지금은 테스트·데모로만 확인된다
- **근속 기준값(3년·설정값)의 근거는 여전히 없다**(절대 원칙 2) — 저장할 수 있게 됐을 뿐이다
- `fell_back` 집계(«베테랑이 부족하다»)를 보는 화면·API 는 없다 — `routing_log` 에 쌓이기만 한다
- 판정 API 에 인증이 없다 — 누구나 부르면 `routing_log` 에 행이 쌓인다(통화 시작과 같은 한계)
- 운영 DB 마이그레이션 필요(`db/migrations/2026-09-15-summary-revision-app-setting.sql`, 311 과 한 파일)
