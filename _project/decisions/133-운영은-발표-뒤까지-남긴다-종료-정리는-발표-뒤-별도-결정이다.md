# 133. 운영은 발표 뒤까지 남긴다 — 종료 정리는 발표 뒤 별도 결정이다

- 날짜: 2026-09-22
- 작성: 정성윤
- 상태: 채택
- 관련: `decisions/122`(상담원 토큰 만료 없음 — 그대로 유지) · `127`(공개 데모 라이브) · `129`(10-27 까지 마감 기간) · `116`(자동 중지 안 함)
- 티켓: `w8-project-closeout`(있으면 — 발표 뒤로 미룸)

---

## 맥락

「완전 마무리」 다섯 조건 중 하나가 「계정·비용·키가 정리됐거나, 남기기로 한 결정 기록이 있다」다.
종료 정리(AWS 자원 내림 · GCP 키 폐기 · 토큰·시크릿 폐기)는 **되돌릴 수 없고**, 발표일을 아직 모른다(`129` 는 기본값).

## 선택지

| | 안 | 판단 |
|---|---|---|
| A | 10-27 에 내린다 | 발표가 그 뒤면 시연할 것이 없다 |
| B | **발표 뒤까지 남긴다.** 종료 정리는 발표일이 확정된 뒤 새 결정으로 | ✅ 채택 |
| C | 전시용으로 계속 둔다 | 월 비용이 계속 나간다. GCP 크레딧은 11-24 만료. 발표 뒤에 다시 정한다 |

## 결정

**발표 뒤까지 운영(EC2 k3s · RDS · Vercel 셋 · GCP STT)을 그대로 둔다.** 종료 정리는 하지 않는다.

- `122`(상담원 토큰 만료 없음)는 **유지**한다 — 폐기로 관리하는 구조가 이미 있고, 발표 전에 만료 컬럼을 넣으면 마이그레이션이 하나 더 생긴다.
- 발표일이 확정되면 그날 기준으로 새 결정 기록을 쓴다 — 남길지(전시) 내릴지(종료 정리). 내리면 순서는 S3 골든셋·평가 결과 내려받기 → AWS 자원 → GCP 키 → 토큰·시크릿 → 저장소 비밀값 스캔.
- 그때까지 비용은 청구 콘솔에서 주간으로 본다(예산 알림은 조직 정책이 막는다).

## 되돌리는 법

발표일이 정해지면 이 파일의 상태 줄에 날짜를 적고 후속 결정 번호를 붙인다.
