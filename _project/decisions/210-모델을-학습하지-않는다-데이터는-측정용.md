## 맥락

프로젝트 초반(`decisions/010`)은 KcELECTRA 등 사전학습 모델을 **파인튜닝**하는 그림이었고, 09-14 에는 학습 장소를 정성윤 개인 PC 로
잡았다. 그런데 09-15~17 실측이 방향을 바꿨다 —

- 학습할 **라벨 데이터가 없다.** 골든셋의 C-1~C-4 라벨(양성 14 · 음성 6)은 채점용이라 학습에 쓰면 평가가 무너진다(절대 원칙 4·5).
  AI Hub 상담원 발화 9,881건에는 위반 라벨이 없다(`w5-classifier-ner-benchmark` 09-15)
- 학습 없이도 필요한 것이 이미 나왔다 — C-5 는 사전학습 NER(`koelectra-ner`) + 규칙으로 골든셋 누락 0(`w5-ner-p6-p7`),
  검색은 사전학습 임베딩 KoE5 + bge 리랭커로 Recall@5 0.979(`206`), B-4 는 kanana 원출력(`207`), C-1~C-4 는 규칙 v1
- 남은 기간(10-27 까지 6주)에 학습 파이프라인·라벨링·검증을 새로 세우면 **측정(E)과 배선(208)이 밀린다**

## 결정

1. **모델을 학습하지 않는다.** `ai/` 의 모델은 전부 사전학습 그대로 쓰고, 품질은 규칙·검색 구성·프롬프트로 만든다.
2. **데이터(AI Hub 전사·다산콜DB 음성·골든셋)는 측정용이다.** S3 에 올려 두고 하네스·측정 스크립트가 읽는다.
   **버킷·경로는 정성윤 님이 정한다**(런북 S3 `assist-apne2` 는 테스트 음성 보관용이고, AI Hub 데이터는 재배포 금지라 **비공개 경로**여야 한다 — 여기서 지어내지 않는다).
3. 수치 기록(§5)에는 **어느 데이터 버전(S3 키)으로 쟀는지** 남긴다.
4. 티켓 정리 — `w3-a5-translation-spike`·`w3-call-temperature` 의 「모델 학습 후 진행」 메모를 **실제 막힘**으로 고친다
   (A-5: AI Hub 505/71479 미신청 · D-5: 통화 단위 음성 골든셋 없음). `w5-classifier-ner-benchmark` 는 「측정 불가 — 학습 안 함」으로 닫는다(지우지 않는다).
5. `ai/apps/training/` 은 지우지 않는다 — 처리 방향(보관·이동)은 미결에 적어 두고 따로 정한다.

## 근거

- 절대 원칙 1·9(판정은 규칙, LLM 은 설명) — 학습 분류기가 없어도 판정 구조는 그대로다
- 절대 원칙 2·10 — 학습한 모델의 성능을 잴 독립 표본이 없으면 그 수치는 기록할 수 없다
- 09-15~17 실측(`206`·`207`·`w5-ner-p6-p7`)이 학습 없이 목표치(Recall@5 ≥0.70·C-5 누락 0)를 넘겼다

## 이 결정으로 말할 수 없는 것 (절대 원칙 10)

- 「학습했으면 더 좋았을 것」 — 재지 않았다. `010` 의 대조군 비교(`w5-classifier-ner-benchmark`)는 **측정 불가**로 남는다
- 사전학습 모델의 도메인 적합성 — 골든셋(작성) 기준 수치이지 실제 통화 분포에서의 값이 아니다

## 되돌리는 법

`ai/apps/training/` 을 지우지 않은 것이 그때를 위한 것이다.
