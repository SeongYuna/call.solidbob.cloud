# 139 — A-5 는 1차 범위(서툰 한국어 전사)만 실물이고, 번역·TTS 확장은 「미착수」로 말한다

- 날짜: 2026-10-01
- 결정자: 정성윤 (PM 기본값 — 129 와 같은 방식. 팀이 반대하면 이 파일에 날짜를 붙여 고친다)
- 관련: `201`(A-5 신설·1차 범위 ⓑ) · 판정문 `_logs/2026-09-30-02`(WER 실측) · 미결 09-21 「A-5 실측 뒤 남은 것」 · 09-22 「A-5 를 차별점으로 유지할지」

## 맥락

기획서는 A-5 를 「사수 — 차별점」으로 둔다. 실물은 ⓑ(서툰 한국어를 정확히 전사)의 **측정**뿐이다 — 숙련도별 WER(초급 **0.412** · 중급 0.266 · 고급 0.225 · 유창 0.198, n 20/등급, 8 kHz, 상한). ⓐ(외국어 → 한글 번역 · 상담원 → 고객 TTS)는 런타임 코드가 0줄이고 화면은 mock 이다.

## 선택지

1. 번역 한 방향(고객 → 한글)을 API 한 겹으로 붙인다
2. **1차 범위만 실물로 말하고, 확장은 미착수로 발표한다.** 통번역 화면은 mock 이라고 밝히며 보여준다
3. 차별점 자리에서 내리고 B(필요서류)를 전면에 둔다

## 결정

**2.** WER 표는 「단어 다섯 중 둘을 틀리는 수준」이라는 문장과 함께 싣고, 이 수치는 **문제의 크기를 보여주는 차별점의 근거**이지 해결의 증거가 아니라고 적는다. 한계 셋(온라인 녹음 다운샘플이라 실전화망보다 좋다 · 민원 어휘가 아니다 · 등급당 n 20)을 값 옆에 붙인다.

## 근거

- 1 은 품질을 잴 표본이 없어 「됐다」고 말할 근거가 안 생긴다(절대 원칙 2).
- 3 은 기획서 구조(`201`)를 발표 준비 중에 흔든다.
- 하네스 안에서 A-5 를 재는 것(STT 포트 + 음성 골든셋)은 하지 않는다 — `scripts/measure_a5_proficiency.py` 로만 잰다.

## 되돌리는 법

Chirp 3 재측정 값(IAM 은 09-22 부여됨)이 나오면 유지/축소를 다시 정한다. 그때까지 「차별점 유지」 여부를 더 묻지 않는다.
