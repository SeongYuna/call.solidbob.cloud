# 126. 배정 판정은 콜 미디에이터가 통화 시작 직후 부른다 — 통화 종료는 화면 버튼 그대로다

- 날짜: 2026-09-21
- 작성: 정성윤
- 상태: 채택 — ~~**구현 전**이다~~ → 2026-09-22 구현(장민석, call-mediator `0.2.4`, 배포 전). 후보 목록은 `ROUTING_CANDIDATES`(비면 빈 목록), 결과는 로그에만 — 화면 표시는 아직. **성격은 `320` 이 정했다 — 완성본의 호출자는 교환기이고 이것은 시연용 대리다**
- 관련: `decisions/313`(J-5 배정 판정 API) · `120`(쓰기 경로 서비스 토큰) · `204`(베테랑 배정) · `306`·`310`(통화 후 초안 · 요약 확정)
- 티켓: `w7-j5-routing-caller`

---

## 맥락

`POST /hub/routing-decisions`(J-5 인입 전 배정 판정)는 09-15 에 만들어졌는데 **아무도 부르지 않는다.** 교환기가 없고
콜 미디에이터도 부르지 않는다(`services/call-mediator/src/adapters/hub_http.ts`). 그래서 `routing_log` 가 비어 있고,
그 테이블의 존재 이유인 「떨어뜨린 건수(`fell_back`)」 집계도 값이 없다. 통화가 시작되는 순간을 아는 것은 미디에이터뿐이라
09-15 부터 조서희·장민석 님 로그에 「정성윤 결정 대기」로 남아 있었다.

같은 자리에서 **통화 종료(`POST /hub/calls/{id}/close`)도 미디에이터가 채널 닫힘에서 자동으로 부를지**가 열려 있었다
(09-16 해결표 2번 — 지금은 상담원 화면의 버튼이 부른다).

## 선택지

| 후보 | 판단 |
|---|---|
| **배정만 부른다 · 종료는 화면 버튼** | 시연에서 J-5 가 보이고 집계에 값이 생긴다. 종료는 사람이 요약을 확정하는 흐름(`310`)과 맞는다 |
| 둘 다 부른다 | 「종료 즉시 요약」이 사람 손을 안 탄다. 대신 화면 버튼과 **같은 통화를 두 번 닫는다** — 서버가 두 번째를 무시하게 맞춰야 하고, 통화 종료 가드가 서비스 토큰과 상담원 토큰을 둘 다 받아야 한다 |
| 둘 다 안 부른다 | 구현이 없다. 발표에 「인입 전 배정은 전화 사업자 연동이 있어야 의미가 있다」고 적는다. 현황판 집계는 계속 0 이다 |

## 결정

1. **콜 미디에이터가 통화 시작(`POST /hub/calls` 성공) 직후 `POST /hub/routing-decisions` 를 부른다.** 쓰기 경로 서비스 토큰을 그대로 쓴다.
2. **통화 종료는 미디에이터가 부르지 않는다.** 상담원 화면의 버튼이 부른다(지금 그대로).
3. 판정이 실패해도 **통화는 막지 않는다** — 배정은 얇은 필터이고(`204`), 전화를 못 받게 만드는 것이 더 나쁘다. 실패는 로그에만 남긴다.

## 구현할 때 정할 것 — 숨기지 않고 적는다

- **후보 상담사 목록(`candidates`)을 어디서 얻는가.** API 는 「지금 받을 수 있는 상담사」를 부르는 쪽이 넘기게 돼 있는데, 미디에이터는 누가 대기 중인지 모른다.
  시연 범위에서는 **미디에이터 설정의 후보 목록**(시연용 상담원 ID)으로 넘기고, 비어 있으면 빈 목록을 보낸다. 빈 목록이면 서버는 「기존 배정 규칙」으로 떨어뜨리고 그 사실을 남긴다
- **발신 번호가 없는 테스트 콜은 늘 「블랙리스트 아님」이다.** 고객을 식별할 수 없기 때문이다(`customer_identified: false`). 시연에서 J-5 를 보이려면 블랙리스트에 올린 고객의 번호로 통화를 시작해야 한다
- 서버 쪽 — 이 경로를 서비스 토큰 문에 넣는다(장민석 님, `w6-open-write-guards` 와 같은 줄기)
- 판정 결과를 상담원 화면 어디에 보일지 — 조서희 님과 맞춘다

## 근거

- 09-16 해결표 8번의 권고(「부른다 — 그래야 시연에서 J-5 가 보이고 집계가 숫자를 갖는다」)
- 통화 종료를 둘로 만들면 이중 호출과 가드 설계가 함께 들어온다. 사람이 확정하는 흐름(`310`·`311`)을 건드릴 이유가 지금 없다
