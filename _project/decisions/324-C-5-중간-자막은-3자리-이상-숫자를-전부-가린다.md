# 324 — C-5 중간 자막은 3자리 이상 이어진 숫자를 전부 가린다

**날짜**: 2026-09-22
**작성**: 장민석 (브랜치 `server`)
**상태**: 채택 — 구현됨(배포 전). 배포 뒤 운영 표본으로 다시 본다
**관련**: 절대 원칙 3(애매하면 가린다) · 미결 「C-5 중간 자막에 번호 앞자리가 가려지지 않고 나간다」

---

## 맥락

운영 표본 6건 중 5건에서 **중간 자막(interim)**에 카드 `9410 0000`·전화 `010 0000` 이 그대로 화면에 나갔다. 확정 자막·DB 는 가려졌다.
코드로 가설이 맞았다 — 확정 규칙(`pii_detector`)은 **완성된 번호**만 잡는다(휴대전화 10~11자리 · 카드 14~16 · 계좌 10~14). 중간 자막은 번호가 들어오는 중이라 8자리·7자리가 어느 패턴에도 안 맞는다.

## 선택지

| | 판단 |
|---|---|
| **중간 자막에만 숫자 가드를 얹는다** — 3자리 이상 이어진 숫자(낭독형 포함)를 전부 | 중간 자막은 곧 확정으로 덮인다 — 넓게 가려도 잃는 것이 순간뿐이다. 확정 규칙·골든셋 채점은 그대로 |
| 확정 규칙에 「번호 앞부분」 패턴을 넣는다 | 확정 자막·DB 에서 금액·호수까지 지워진다. 골든셋 과잉 마스킹이 는다 |
| 중간 자막을 화면에 안 보낸다 | 실시간 자막(A-3)이 확정까지 멈춘다 — 기능을 잃는다 |

## 결정

**중간 자막 전용 어댑터** `InterimMaskingAdapter` — 어떤 마스킹 구현(규칙, 규칙+NER)이든 감싸고 그 결과에 `interim_digit_guard` 를 얹는다.
인터랙터는 `is_final` 로 포트를 고르기만 한다(판정은 어댑터).
- 구분자·공백을 걷은 뒤 **3자리 이상** 이어진 숫자를 가린다 · 두 자리 이하(「2개」·「30분」)는 남긴다 · 구분자는 남긴다(자릿수 보존)
- 라벨은 P1~P7 안에서 — 문맥어가 있으면 그 패턴, 없으면 0 으로 시작하면 P4, 그 밖은 P3. 새 패턴을 만들지 않는다(프론트 계약도 P1~P7)

## 근거

- 절대 원칙 3: 누락 0건 > 과잉 억제. 중간 자막의 과잉은 확정에서 돌아온다
- 확정 규칙을 건드리지 않아 골든셋 채점 결과가 바뀌지 않는다

## ⚠ 남는 것

- **확정 자막도 번호가 두 발화로 쪼개지면** 같은 구멍이 있을 수 있다(미확인) — 운영 표본에서 본다
- 띄어 쓴 한자어 숫자가 이어지면(「이 일이」) 중간 자막에서만 가려진다

## 되돌리는 법

`transcript_ingest_provider.py` 의 `interim_masking=` 을 빼면 중간 자막도 확정 규칙만 탄다.
