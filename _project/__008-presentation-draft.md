## 1. 한 줄

서울시 120 다산콜센터 상담원 옆에서 통화를 실시간으로 들으며 **그 민원에 필요한 구비서류를 띄우고**,
개인정보를 **그 자리에서 가리고**, 상담원 위반과 고객 폭언을 잡는 상담원 어시스트.

> **판정은 규칙이, 설명만 모델이 한다.** 이 한 문장이 설계 전체를 지배한다 — 왜 그런지는 §13.

## 2. 누구의 어떤 문제인가

- **서류를 외울 수 없다.** 다산 서류 문의 **2.18%(146건)** 가 **64종 서비스**에 흩어져 있다(09-11 재측정).
  빠뜨리면 고객이 헛걸음한다 — 그래서 **재현율 우선**이다.
- **한국어가 서툰 민원인이 는다.** 체류외국인 **287만 명**(2026-06-30). 서툰 한국어 발화의 STT 단어 오류율이
  **초급 0.412 · 중급 0.266 · 고급 0.225 · 유창 0.198**(등급당 n 20, 8 kHz 전화 대역, Google STT v1 기본 모델).
  **초급은 단어 다섯 중 둘을 틀린다.**
  ⚠ 이것은 **문제의 크기이지 우리가 푼 증거가 아니다.** 우리가 한 것은 「재는 것」까지다(§5).

## 4. 아키텍처 한 장

```
상담원 브라우저(React)  ⇄ WS ⇄  콜 미디에이터(Node)  →  서버(FastAPI 허브 + 스포크 14)
                                                          ├ PostgreSQL 29 테이블
                                                          └ Elasticsearch (nori + dense_vector)
단일 EC2(c7i.2xlarge) · k3s · GPU 없음 · 프론트 셋은 Vercel
```

**허브-스포크**다. 허브는 포트(계약)만 알고 구현체를 모른다 — `import-linter` 계약 **8종**(server 5 · ai 3)이
CI 에서 그 방향을 강제한다. 그래서 「검색을 BM25 로 되돌린다」 같은 교체가 **배선 한 줄**이다.

### ⟨문구 셋⟩ — 슬라이드에 같이 넣는다

1. **「누락 0」은 오류 없는 전사 한정**이다. 오류를 넣으면 규칙만은 5%에 1건, 규칙+NER 은 15%부터 2건 샌다.
2. **오류 내성 곡선은 낙관 쪽**이다. 주입기가 실측 편집의 **46.9% 를 흉내 내지 못한다.**
3. **F-2 의 1.0 은 「팀이 만든 규칙표 안에서의 1.0」**이다(절대 원칙 10).
   컴플라이언스·콜 가드의 1.0 도 **규칙이 만든 표본을 같은 규칙으로 채점한 자기충족 상한**이라 성능이 아니다.

**근속 3년 · 블랙리스트 6개월 · 보존 180일은 예시값**이다(`141`) — 근거를 찾은 값이 아니다.

⚠ **D-1 요약 포함률 0.883 은 「규칙 발췌」의 값**이다(10통화 60항목). 운영은 10-02 부터 **모델 요약**이고,
**모델의 포함률은 아직 재지 않았다**(미결). 0.883 을 지금 요약의 성능으로 말하지 않는다.

## 7. 트래픽을 견디는가 — 재 봤습니다

**2026-10-08 운영 노드에서 부하 시험.** 질의는 매번 다르게 만들어 캐시를 피했고, 오류율 20%·p95 30초에서 자동 중단하게 했다.

| | 대조 `GET /health` | 실제 `POST /hub/search` |
|---|---|---|
| 동시 1 | p95 5 ms · 651 req/s | **196 ms** · 5.3 req/s |
| 동시 4 | p95 4 ms · 1,122 req/s | **500 에러 시작** (19/20) |
| 동시 8 | — | 500 ×3 (37/40) |
| 동시 16 | p95 14 ms · **1,246 req/s** | p95 1,501 ms · **29% 실패 → 자동 중단** |

**HTTP 계층은 멀쩡하다** — `/health` 는 동시 16 에서도 1,246 req/s 다. 깨지는 것은 **검색 경로 안**이다.

### 원인 — 토크나이저를 공유한다

```
RuntimeError: Already borrowed
  ai/apps/retrieval/adapter/outbound/koe5_embedder.py:76
  → tokenizer(batch, padding=True, truncation=True, …)
  → transformers/.../set_truncation_and_padding → self._tokenizer.enable_truncation(...)
```

HuggingFace fast tokenizer 는 **Rust `RefCell` 기반**이고, `padding`·`truncation` 설정을 **호출할 때마다 객체에 쓴다.**
서버는 **단일 uvicorn 워커**(`--workers` 없음)라 그 인스턴스 **하나를 스레드풀이 공유**한다 —
동시 요청이 같은 설정을 만지면 Rust 쪽에서 「이미 빌려 갔다」며 터진다.
로그의 예외 **27건이 전부 이것**이고, 동시성에 비례해 **0 → 1 → 3 → 23 건**으로 늘었다.

### 고치는 법 — 셋 다 안다

| 방법 | 효과 | 비용 |
|---|---|---|
| `threading.Lock` | 500 제거. 병렬은 그대로 | 한 줄 |
| `threading.local()` 토크나이저 | 500 제거 **+ 병렬 확보** | 수십 줄 |
| `uvicorn --workers N` · 레플리카 | 프로세스가 갈려 **공유 자체가 없다** | **모델 메모리 × N**(약 680 MB × N) |

### 왜 넣지 않았나

**10-08 에 프로젝트를 고정했다**(`138`). 시연은 동시 1~2 라 이 천장에 닿지 않는다.
**남은 기간에 운영을 흔드는 것보다, 천장을 아는 채로 두는 쪽을 골랐다.**

### 규모가 커지면

레플리카 + HPA 로 세 번째 방법을 쓴다. 단일 노드 k3s 를 고른 것은 **비용·기간 결정**이고(`124`·`146`),
**수평 확장의 실제 제약이 모델 메모리라는 것까지 안다** — 그래서 `GENERATION_MODEL` 은 끝내 안 켰다.

> ⚠ **이 시험의 한계** — 단계마다 질의 번호를 0부터 다시 세어 **앞 단계가 던진 질의가 캐시에 맞았다.**
> 그래서 **p50 은 못 쓴다**(동시 2 의 4 ms 가 그 흔적이다). **유효한 것은 동시 1 의 196 ms · 오류율 · p95 뿐이다.**
> 노드는 끝까지 한가했다(`load average` 0.05 → 0.19) — **단일 워커라 8 vCPU 중 한 코어도 다 못 쓴다.**

## 8. 실패 사례 — 지우지 않는다 (절대 원칙 8)

- **B-0 도메인 분류 0.857 폐기** — 지표 자체가 틀렸다. 08-27 의 Recall 0.857(n 14)도 4도메인 값이라 무효다.
- **공개 문서에 잰 적 없는 숫자가 실려 있었다** — 「오류 10%에서 0.48 → 하이브리드로 0.66」. 09-28 에 실측 곡선으로 정정했다.
- **배포에서 네 번 데었다** — `/health` 는 ok 인데 스키마 미적용으로 500(09-14) · 태그를 안 올려 **옛 이미지 재배포**(09-10) ·
  Vercel 한도(09-22) · 같은 자리를 또 밟아 `tag-check` 를 **별도 워크플로로** 떼어냈다(`111`·`131`).
- **수동 QA 1회차 ❌ 7건 → 2회차 ✅** — 화면 결함은 **API 왕복으로는 보이지 않았다.** 사람이 눌러야 나왔다.
- **절차 채택이 맞장구에 엉뚱한 서류를 띄웠다** — 세 번 고쳐 세 번 「잡음을 없애면 기능이 죽는다」를 만났고,
  네 번째에 **점수 하한 0.635**로 멈췄다(`219`).
- **모델이 규칙을 못 이겼다** — F-3 브리핑 범주 판정에서 **모델 0/9 · 규칙 6/9**. 그래서 **판정을 규칙으로 되돌렸다**(`220`).
- **테스트가 시각에 걸려 깨졌다** — 번호 누출 검사가 통화 시작 시각의 마이크로초 `840108` 안의 `010` 에 걸렸다(10-06).
  **번호는 안 샜다.** 꼴로 보도록 고쳤다.

| **화자 분리** | 한 줄 녹음에서 두 사람 가르기는 **한 번도 검증되지 않았다** |
| **통화 온도(D-5)** | 통화 단위 음성 골든셋이 없어 **측정 불가**. 화면은 「미측정」을 낸다 |
| **통화 소유 범위** | 로그인한 상담원끼리 **서로의 통화가 보인다**(`w8-call-owner-scope`) |
| **C-6 대응 베타** | **상담원 PC 에서만** 안내 음성이 난다 — 고객에게 보내는 경로가 없다 |
| **B-6 자동 추천** | 맞장구에도 카드가 뜬다. 기권은 수동 검색에만 |
| **D-4 공백 리포트 · G-2 지역자원** | 미착수 |
| **곡선·기준선** | 오류 내성 곡선은 **한 세대 앞 판**. 기준선이 **BM25 구성 하나**에만 있다 |
| **동명이인** | 이름을 식별자로 쓴다(`409`) |

## 11. 개인정보를 어떻게 다루는가 — 늦게 뒤집은 결정

처음에는 **상담원 화면에도 마스킹본**을 보냈다. 10-06 에 뒤집었다(`326`) — **상담원은 번호를 눈으로 확인해야 한다.**

```
화면(/ws)    제 번호는 010-9876-5432 이에요     ← 원문 + 「저장 시 가림」 표시
API·DB       제 번호는 *************  이에요     ← 마스킹본
DB 실제 값   enc:v1:wkzHqB9TibLIiOeN…            ← AES-256-GCM (10-08 부터)
```

- 가리는 일은 **저장·요약 앞단**에서 서버가 한다. 그래서 **SEC-1(원문 미보관)은 그대로 성립한다.**
- **전사 본문은 2026-10-08 부터 암호화**한다. 키는 **클러스터 밖**(SSM Parameter Store SecureString)에 둔다 —
  **키를 잃으면 되돌릴 수 없어서** 보관처를 먼저 정했다.
- 운영에서 넷을 다 확인했다(10-08) — 화면 원문 · API 마스킹본 · DB `enc:v1:` · 추천 등 **자막 밖 메시지에는 원문이 없다.**

## 12. 시연

`_project/demo-script.md` 순서. **1막** 통화(서류 카드 → 마스킹 → 콜 가드 → 컴플라이언스 → 체크리스트)
→ **통화 중 직접 검색**(없는 것은 「없음」) → **후처리**(모델 요약 → 수정 → 확정) → **블랙리스트 요청**
→ **관리자 승인·감사 기록**(뒤 4자리만) → **2막 재통화 배정 배너** → **지난 통화 보기**(개인정보 가려진 채).

⚠ **녹화 전 `act1` 을 한 번 예열한다** — 배포 직후 첫 통화는 카드가 2~5초 늦다.
서버를 내렸다 올린 날은 그 예열이 **요약 모델 예열을 겸한다**(첫 요약 14.5초 → 그 뒤 3.7초).

## 13. 물으면 답할 것

| 질문 | 답 |
|---|---|
| **왜 규칙인가? LLM 쓰면 되지 않나** | 같은 입력에 같은 답이 나와야 **재현 가능한 평가**가 된다. 그리고 실제로 **모델이 규칙을 못 이겼다**(F-3 0/9 대 6/9). LLM 은 **채점자로도 쓰지 않는다**(절대 원칙 1·9) |
| STT 는? | 영상은 글자 채널이 많다. 구글 스트리밍은 **운영에 있고** 2채널로 돈다. **화자 분리는 미검증** |
| 통번역은? | **1차 범위만 실물.** 번역·TTS 는 미착수 — 잴 표본이 없어 「됐다」고 말할 근거가 없다 |
| 숫자는 어떻게 나왔나 | 하네스 `--record` → **운영 RDS `eval_run`**. 언제·어느 커밋·어떤 명령·표본 몇 건이 **행으로 남는다** |
| 1.0 이 너무 높은데 | **맞다.** F-2 는 우리가 만든 규칙표 안의 값이고, 컴플라이언스·콜 가드는 자기충족 상한이다. 그래서 **성능으로 말하지 않는다** |
| **요청이 몰리면?** | **재 봤다**(§7). 동시 4부터 500 이 나고 원인은 토크나이저 공유(`Already borrowed`)다. 고치는 법 셋을 알고, **고정 중이라 안 넣었다**고 말한다 |
| 운영에서 진짜 도나 | `/health` 스포크 **14** · 문 둘 `locked` · `transcript_encryption on`. 수동 QA **3회차**까지 돌렸다 |
| 남은 기간에 뭘 할 건가 | **아무것도 더 넣지 않는다.** 10-08 에 고정했다(`138`) — 발표·회고·영상만 |
