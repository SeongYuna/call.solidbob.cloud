## 실패 시 대체 경로

- 통화가 끊기면(배포·순단): 상담원 화면은 스스로 다시 붙는다(10-01 재연결). 스크립트는 `--call-id <같은 ID>` 로 이어서 보낸다 — 0.2.12 는 5분 유예 안이면 절차·상담원 발화를 잇는다.
- 카드가 안 뜨면: 검색 스포크 확인 `health` 의 `retrieval_dense`. 안 되면 수동 검색으로 대체.
- 블랙리스트 요청이 「고객이 식별되지 않았습니다」: 스크립트가 헤더를 못 실은 것 — `--phone` 확인.
- 전체 실패: 09-30 QA 2회차 스크린샷 + 이 대본으로 설명. 녹화는 **두 번** 찍어 둔다.
