- **AWS 를 Terraform 이 아니라 콘솔로 세우기로 했다** (사용자 지시). Terraform 코드는
  **지우지 않고** 설계서로 남긴다 — 무엇을 왜 만드는지가 거기 적혀 있고, 나중에 코드로
  옮길 때 `terraform import` 로 기존 리소스를 넣으면 된다.
  ⚠ **둘을 같이 돌리지 않는다** — Terraform 은 콘솔로 만든 것을 모르기 때문에
  **리소스가 두 벌 생긴다.** `infra/terraform/README.md` 맨 위와 `infra/README.md` 표에 못 박았다.
- **`infra/aws-console-setup.md` 를 썼다** — 예산 알림 → 키 페어 → 보안 그룹 2개 → EC2 →
  탄력적 IP → RDS → 접속·도커 → 배포 → DNS·HTTPS → 확인. 처음 하는 사람이 그대로 따라갈 수
  있게 **화면 이름과 고를 값을 전부** 적고, 자주 걸리는 곳 7가지와 **정리(삭제) 절차**를 붙였다.
- **콘솔 절차는 Terraform 코드와 한 군데가 다르다 — VPC 를 새로 만들지 않고 기본 VPC 를 쓴다.**
  서브넷·라우팅·IGW 가 이미 있어 클릭 수가 크게 줄고, 데모 규모에서 잃는 것이 없다.
  **다른 점을 문서에 적어 뒀다** — 안 적으면 나중에 코드로 옮길 때 왜 안 맞는지 모른다.
- **⚠ 어제 적은 비용 설명이 틀렸다 — 정정했다.** 「EIP 는 인스턴스에 붙어 있으면 무료」라고
  적었는데 **2024-02-01 부터 모든 퍼블릭 IPv4 가 시간당 $0.005(월 ~$3.6) 과금**된다.
  옛 규칙을 그대로 쓴 것이다. 월 추정을 **~$48 → ~$52** 로 고쳤고
  (`infra/terraform/README.md`·`compute.tf`), 자동 할당 IP 를 써도 요금이 같아서
  **아낄 수 있는 항목이 아니라는 점**도 함께 적었다. 대신 **인스턴스를 지우고 EIP 를 안 지우면
  계속 나가므로** 정리 절차에 「릴리스」를 넣었다.
- **문서에 박아 둔 함정 셋** (실제로 초보자가 가장 많이 걸리는 곳) —
  ① **RDS 「추가 구성」이 접혀 있어 「초기 데이터베이스 이름」을 놓친다** — 비우면 DB 자체가
  안 만들어지는데 생성은 성공해서 나중에야 안다 ② **EC2 네트워크 설정 기본값이 「보안 그룹 새로
  생성」**이라 그냥 넘기면 앞서 만든 `callguard-web` 이 안 붙는다 ③ **`usermod -aG docker` 뒤
  재로그인**을 안 하면 계속 `permission denied` 가 난다.
- **보안에서 의도적으로 안 연 것**: 9200(ES)·5432(PostgreSQL)를 보안 그룹에 넣지 않았다.
  ES 는 `xpack.security` 를 끈 채로 도는 구성이라 열면 **인증 없는 검색 엔진을 공개**하는 것이 된다.
  RDS 는 「퍼블릭 액세스 아니요」 + 소스를 IP 가 아니라 **`callguard-web` 보안 그룹**으로 걸었다 —
  EC2 를 갈아끼워도 규칙이 따라온다.
- **검증**: 지킬 빌드 95페이지 · 깨진 내부 링크 0건. ⚠ **콘솔 절차 자체는 아직 실행하지 않았다** —
  지금 뜬 리소스는 **0개**다. 사용자가 화면을 따라가며 만드는 중이다.
- **남은 것**: 절차 1~10 을 실제로 수행. 특히 8-3 에서 `compose.prod.yml` 의
  `build.context: ../elasticsearch` 때문에 심볼릭 링크가 하나 필요한데, **이건 문서로만
  확인한 것이고 서버에서 실행해 본 적이 없다** — 첫 배포에서 걸리면 여기부터 본다.
