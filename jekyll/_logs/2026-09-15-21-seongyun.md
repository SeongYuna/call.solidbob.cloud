- **Vercel 미리보기 배포가 계정 하루 한도에 걸렸다 — 셋 다 Ignored Build Step 을 걸어 막았다.**
  PR #94 에서 `admin`·`kxu6` 가 `Deployment rate limited — retry in 24 hours` 로 빨간 X 였다.
  원인은 **프로젝트 셋 × 모든 브랜치 push** 다 — `apps/` 를 한 줄도 안 고친 커밋(CI·문서·`server/`)까지
  프로젝트마다 미리보기 배포를 하나씩 만든다. 오늘 다섯 브랜치에 push·머지가 몰려 한도에 닿았다.
  - 걸어 둔 값(셋 동일): Behavior `Custom` · Command `git diff --quiet HEAD^ HEAD -- ./` ·
    Production Overrides 는 비움. 종료 0 = 건너뜀 / 1 = 빌드.
  - 랜딩(`call-solidbob-cloud`)만 통과했던 이유가 **거기만 이미 걸려 있었기 때문**이다.
- **프로젝트 이름이 도메인과 어긋나 있다 — 런북에 대조표를 넣었다(18-4).**
  같은 저장소를 세 번 Import 해서 Vercel 이 접미사를 붙였다:
  `call-solidbob-cloud` = **www**(랜딩, `apps/platform`) · `call-solidbob-cloud-kxu6` = **call**
  (상담원, `apps/call`) · `call-solidbob-cloud-admin` = **admin**(`apps/admin`).
  이름만 보고 `call-solidbob-cloud` 를 상담원 화면으로 읽기 쉽다 — 실제로 이 세션에서 한 번 틀렸다.
- **⚠ 이 설정의 함정을 함께 적었다** — `./` 는 **Root Directory 기준**이라, 그 값이 실제 폴더와
  어긋나면 `git diff` 가 항상 비어 **빌드가 영원히 건너뛰어진다.** 빨간불이 아니라 조용한 초록이다.
  09-14 `apps/dashboard` → `apps/call` 개명이 있었고, 미결 항목에도 옛 경로가 남아 있어 함께 고쳤다.
  확인법도 적었다 — `server/`·CI 만 고친 PR 이면 Vercel 체크 **셋 다** `Canceled by Ignored Build Step`
  이어야 한다. 하나라도 빌드가 돌면 그 프로젝트의 Root Directory 가 어긋난 것이다.
- **같은 병을 또 만났다 — 설정이 콘솔에만 있다.** 오늘 `branch-protection.json`·`ruleset-main.json` 이
  어긋나 있던 것과 구조가 같다. `vercel.json` 으로 옮길지는 **`apps/` 가 조서희 전담**이라 혼자 못 정한다 —
  미결로 올렸다(선택지 둘 + 「Root Directory 는 어느 쪽이든 콘솔에 남는다」).
