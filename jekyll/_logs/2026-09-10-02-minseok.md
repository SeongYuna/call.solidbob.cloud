- **ngrok 터널을 열었다** — `https://grandma-unwritten-scouring.ngrok-free.dev` → 로컬 서버 8000. 터널 경유로 `/health`(스포크 4종)·`POST /hub/recommendations`(트리거 발동 + 로컬 ES 카드)가
  실제 응답으로 돌았다. `localhost:5173` origin 의 CORS preflight 도 200. 임시 도메인이라 ngrok 을 재시작하면 주소가 바뀐다 —
  고정 도메인은 대시보드에서 만들어야 해서 아직 없다.
- **무료 플랜 경고 페이지를 확인했다.** 헤더 없이 브라우저처럼 GET 하면 JSON 대신 ngrok HTML 이 온다. 요청에
  `ngrok-skip-browser-warning: 1` 을 붙이면 통과한다. 서버 CORS 가 `allow_headers=["*"]` 라 이 헤더의 preflight 도 이미 허용된다.
- **basic auth 는 일부러 안 걸었다.** 브라우저 CORS preflight(OPTIONS)에는 Authorization 이 실리지 않아 ngrok 이 401 로 끊고,
  그러면 프론트 fetch 가 통째로 실패한다. «서버에 인증이 없다» 는 [미결](/open-items/)에 그대로 남긴다.
