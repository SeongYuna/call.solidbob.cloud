- **프론트 두 화면을 정성윤 Vercel 계정으로 옮기고 공개 주소에 붙였다.**
  소개 `www.solidbob.cloud`(`apps/platform`) · 데모 **`call.solidbob.cloud`**(`apps/dashboard`).
  둘 다 Git 연동이라 `main` 머지로 배포된다. 경위·되돌리는 법: `_project/decisions/106`.
- **⚠ 조서희가 도메인을 놓아줄 필요가 없었다 — 예상이 틀렸다.** `decisions/106` 초안은
  「조서희가 Remove → 정성윤이 Add」 순서로 다운타임을 각오했는데, `Add Existing` 을 먼저
  시도하니 Vercel 이 **TXT 검증 챌린지**를 줬다. 새 `_vercel` 값 2건을 클라우드플레어에 넣는
  것만으로 도메인이 넘어왔다. **체감 다운타임 없음** — 전환 전후 `www` 가 계속 200 이었다.
  절차서에 「먼저 시도해 보고 막히면 해제로 간다」를 넣어 둔 것이 그대로 맞았다.
- **⚠ 「CNAME 해시가 한 글자도 틀리면 안 된다」는 이 저장소의 옛 서술이 틀렸다.**
  `www` CNAME 은 아직 **조서희 프로젝트 해시(`ea6aaafa…`)** 인데 정상 서빙된다 —
  Vercel 엣지는 CNAME 값이 아니라 **Host 헤더로 프로젝트를 판단**한다. 해시는 대시보드 설정
  검증용 표식이다. `_project/dns-solidbob-cloud.md` 에 실측으로 정정했다.
  (바꾸려면 `Add record` 가 아니라 기존 행 **`Edit`** 다 — 한 이름에 CNAME 은 하나뿐이다.
  사용자가 여기서 한 번 막혔다.)
- **대시보드는 mock 모드로 올렸다 — 의도한 것이다.** `VITE_GATEWAY_WS_URL` 이 비면
  `MockGatewayClient` 로 도는 구조라(`src/lib/ws/index.ts`) **환경변수를 아무것도 넣지 않았다.**
  `services/gateway` 는 코드가 0줄이고 `server` 도 안 떠서, 넣었으면 없는 게이트웨이를 찾다
  화면이 죽었을 것이다. 번들에 `ws://`·`wss://` 가 **하나도 없는 것**으로 확인했다.
- **주소를 `dashboard` → `call` 로 옮겼다.** 처음 `dashboard.solidbob.cloud` 로 붙였는데
  `decisions/104` 가 `call` 을 프론트 데모에 배정해 뒀다. **비워 두면 아무도 안 쓰는 이름이
  된다** — `102` 가 지킬을 붙이려다 `104` 가 프론트에 넘긴 이름이다. `call` 을 먼저 붙여
  200 을 확인한 뒤 `dashboard` 를 뗐다(Vercel·클라우드플레어 양쪽). 무중단.
- **검증은 번들 대조로 했다.** 두 배포 모두 **라이브가 로컬 프로덕션 빌드와 바이트 단위 일치** —
  `apps/platform` 158,140 · `apps/dashboard` 243,906(+CSS 30,907). 이 방법으로 **낡은 랜딩이
  6일 떠 있던 것도 찾아냈다** — 응답 코드만 보면 200 이라 멀쩡해 보인다.
- **문서를 실제 배치에 맞췄다** — 지킬 표지(「소개 페이지」·「데모 사이트」로 분리) ·
  `README.md` · `_project/STATE.md` 인프라 줄 · `_project/dns-solidbob-cloud.md` 존 현황표 ·
  `decisions/106`(상태 완료 + 실제 경로 기록). 티켓은
  [w3-vercel-account-migration](/backlog/w3-vercel-account-migration/) `done`,
  [w3-dashboard-deploy](/backlog/w3-dashboard-deploy/) 신규(`done`).
- **⚠ 아직 안 본 것 하나 — `main` 머지로 자동배포가 실제로 도는가.**
  **6일간 아무도 멈춘 걸 몰랐던 이유가 정확히 이 확인의 부재였다.** 지금까지 확인한 것은
  「수동 배포 결과물이 맞다」이지 「자동으로 돈다」가 아니다. **이 정리를 담은 PR 이 첫 시험이다.**
- **남은 것**: ① PR 머지 후 Vercel 이 스스로 배포하는지 확인 ② `www` CNAME 을 새 해시로
  `Edit`(동작에는 영향 없고 대시보드 경고만 남는다) ③ `docs` CNAME 을 `seongyuna.github.io` 로
  ④ `api`(TLS 미발급)를 고칠지 `server` 로 일원화할지 — `105` 기준으로는 후자.
