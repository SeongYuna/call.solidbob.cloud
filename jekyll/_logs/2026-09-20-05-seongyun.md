- **운영 왕복에서 찾은 결함 넷 중 나머지 둘을 다뤘다 — `/close` 는 끝까지, 쓰기 경로 인증은 1단계까지.**
  (둘 다 server `0.1.19` 에 실었다. `decisions/302` 에 따른 변경이고 장민석 님 검토 대상이다.)
- **`/close` 가 통화를 실제로 닫는다.** 전에는 요약 초안만 쓰고 `status`·`ended_at` 을 아무도 안 건드려
  끝난 통화가 영원히 `in_progress` 였다(09-17 로컬 E2E 24건 전부 · 09-20 운영 왕복에서 재현).
  - 요약을 쓰는 **같은 UPDATE·같은 트랜잭션**에서 `status='closed'`·`ended_at` 을 채운다.
    `COALESCE("ended_at", now)` 라 초안을 다시 만들려고 여러 번 닫아도 **끝난 시각은 처음 닫은 때**로 남는다.
  - **값을 조서희 님과 맞춰야 한다고 했던 것은 기우였다** — 프론트의 `"ended"` 는 DB 값이 아니라 **마이크 세션의 로컬 UI 상태**이고,
    API 타입에는 `call.status` 문자열이 아예 정의돼 있지 않다. `closed` 는 새로 정한 값이 아니라 integration 테스트 7곳이 이미 쓰던 값이다.
  - 확정본 보호(409)가 먼저다 — 확정된 통화는 닫는 UPDATE 까지 가지 않는다(테스트로 고정).
  - 이 머신엔 PostgreSQL 이 없어 integration 테스트는 **CI 에서만** 돈다. 그래서 가짜 커서 단위 테스트 둘을 따로 붙였다.
- **쓰기 경로에 서비스 토큰 문을 달았다 — `_project/decisions/120`. ⚠ 1단계라 문은 아직 열려 있다.**
  - **상담원 토큰을 쓰지 않은 이유**: 이 경로를 부르는 것은 사람이 아니라 **콜 미디에이터**다. 미디에이터에 「어느 상담원」의 토큰을 넣을지 답이 없다.
  - **대상을 전수 확인으로 갈랐다** — 미디에이터가 부르는 쓰기 여섯(`POST /hub/calls`·`/transcripts`·`/recommendations`·
    `/call-guard-checks`·`/compliance-checks`·`/required-docs-checks`) + 아무도 안 부르는 `/closure-checks`.
    **프론트 세 앱은 이 일곱을 한 곳도 부르지 않는다.** 반대로 대시보드가 직접 부르는 쓰기(`/close`·요약 확정·카드 피드백)는
    **넣지 않았다** — 브라우저는 서비스 비밀을 가질 수 없고, 넣으면 화면이 깨진다. 그쪽은 사람 토큰 몫으로 남겼다.
  - 일곱 라우터가 전부 라우트 하나씩이라 **합성 루트(`main.py`) 한 곳**에서 걸었다. `GET /hub/calls`(목록)는 라우터가 달라 영향이 없다(테스트로 고정).
  - 모양은 업로드 문(`decisions/110`)과 같다 — `Authorization: Bearer`, 바이트 `compare_digest`(비-ASCII 입력에 500 이 나지 않게).
  - **다른 점 하나 — 토큰이 없으면 연다.** 서버를 먼저 배포하는 순간 돌고 있는 미디에이터가 401 이 되지 않게 하려는 **이행기 동작**이다.
    **조용히 열려 있지 않게** `/health` 에 `ingest_guard: "open"|"locked"` 를 실었다(값이 아니라 상태만).
  - **남은 순서**: ② 미디에이터가 토큰을 헤더로 보낸다(TS — 이 머신에서 테스트 못 돈다) ③ 시크릿에 같은 값을 넣는다 → 이때 잠긴다
    ④ 서버를 fail-closed 로. **③을 ②보다 먼저 하면 운영 통화가 전부 401 이다** — 결정 기록·`secret.example.yaml`·미결에 같은 경고를 적었다.
- **`Settings` 에 필드를 하나 더하자 테스트 4건이 깨졌다** — `test_connection.py` 가 설정을 **전 필드를 손으로** 짓는다.
  기본값을 주어 피하지 않고 그 목록에 새 필드를 더했다(이 파일의 관례 — 설정은 전부 명시한다).
- **`.env.example` 은 건드리지 않았다** — 자격증명 보호 훅이 막는 파일이라 **일부러 우회하지 않고** 미결에 사람 몫으로 남겼다.
  `infra/k8s/base/secret.example.yaml` 에는 키 이름과 경고를 넣었다.
