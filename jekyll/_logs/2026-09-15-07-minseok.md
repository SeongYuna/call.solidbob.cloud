- **추천 카드에 `card_id` 를 실었다**(`decisions/308`). 알고 보니 **추천을 한 번도 저장하지 않고 있었다** — 그래서 줄 id 자체가 없었다.
  발동한 추천을 `recommendation` + `recommendation_card` 에 남기고 돌아온 id 를 싣는다. 내부 지연은 저장 **전**에 잰다 · 빈 카드(관련 문서 없음)도 행을 남긴다 ·
  근거 조항은 `document` 에 있을 때만 잇는다(운영 `document` 비어 있어도 실패 안 함) · 통화 없으면 404 · DB 없으면 `card_id: null`.
  실제 앱 + postgres:17: 통화 없이 404 → 추천 `card_id "1"` → 그 id 로 카드 피드백 201.
