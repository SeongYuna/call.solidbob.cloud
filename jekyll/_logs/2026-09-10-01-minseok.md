- **목표는 하나였다 — 정성윤 부재 중에 조서희가 내 백엔드 API 를 받게 하는 것.** 운영 서버는 ES 적재가
  안 돼 있어, 내 로컬 서버(Neon + 로컬 ES)를 ngrok 으로 내보내기로 했다([w3-api-tunnel-handoff](/backlog/w3-api-tunnel-handoff/)).
  Vercel·게이트웨이는 건드리지 않는다 — 프론트가 필요한 것은 API 주소 하나다. 처음에는 가짜 게이트웨이 +
  Vercel 재배포 그림을 그렸다가 "API 만 받으면 된다"는 한 마디에 범위를 줄였다.
- **내보내기 전에 실제로 쳐 보니 세 겹이 막혀 있었고, 전부 `server/` 소관이라 고쳤다.**
  ① **`call` 행이 없으면 전사 저장이 500** — 외래키인데 통화를 만드는 경로가 없었다. `POST /hub/calls` 를
  슬라이스 단면대로 만들었다(멱등, `_project/decisions/301`, [w3-call-start-api](/backlog/w3-call-start-api/)).
  ② **커넥션 팩토리가 `DATABASE_URL` 을 안 읽었다.** 운영은 그것 하나만 주입한다(런북 12-2). `/health` 는
  `postgres_configured: true` 였지만 실제 연결은 호스트 없이 시도되는 구조였다 — 운영에서 저장이 된 적이
  있는지 확인이 필요하다. ③ **추천이 501** — 트리거 스포크가 안 꽂혀 있었다. 류준이 `ai/provider.py` 에
  남긴 팩토리를 `main.py` 에 꽂았다(`w3-trigger-v1` 의 "장민석 님 몫"). `/health` `spokes` 가 4종이 됐다.
- **운영 부작용 하나를 미리 막았다.** 트리거가 꽂히면 운영의 `/hub/recommendations` 가 501 에서 **500**
  (`index_not_found_exception`) 으로 바뀐다 — 운영 ES 가 비어 있어서다. 코드 오류로 읽히지 않게 **503 +
  "적재해야 한다"** 로 돌려주는 핸들러를 합성 루트에 뒀다. 기동 시 ping 은 하지 않는다(ES 가 잠깐 죽었다고
  마스킹까지 멈추면 안 된다는 기존 원칙 그대로).
- **배선 뒤 기존 테스트 3건이 깨졌고 둘 다 테스트 쪽 문제였다.** lifespan 이 테스트가 미리 꽂은 스텁 트리거를
  덮어썼다 → `setdefault` 로 "빈 자리만 채운다". 헬스 테스트가 남긴 `es.internal` 오버라이드가 다음 테스트로
  샜다 → 전에는 트리거 501 이 먼저 막아 안 보였다. `tests/conftest.py` 에 자동 초기화 픽스처를 뒀다.
- **확인**: 로컬에서 `POST /hub/calls` → `POST /hub/transcripts`(P4 마스킹 + Neon 저장, `masking_event` 행 확인)
  → `POST /hub/recommendations`(트리거 발동 `trigger_at_ms=3346`, 로컬 ES 카드 3장) 가 실제 응답으로 돌았다.
  같은 통화 재알림은 `created: false`. `server` 286 통과 · 계약 4종 KEPT. 로컬 ES 인덱스는 도메인 4종 시절
  102건이 남아 있어 다산 20조항으로 재적재했다.
- **정직하게 적어 둘 것**: "여권 재발급 서류" 질의에 BM25 상위 카드가 `DASAN-MANUAL-4.1`(의학적 판단 금지)이고
  `증명서 발급` 은 2위였다. 검색 품질은 4주차(nori 사용자 사전·dense·RRF) 몫이라 여기서 손대지 않았다.
- **Neon 스키마 대조**: 17 테이블·컬럼·PK·FK·CHECK·COMMENT 29건이 `db/schema.sql` 과 차이 0건. 다만 DDL 자체가
  rev.5 이전이다 — `call.domain` 4종, `closure` 증거 컬럼이 전부 금융·쇼핑, `verdict` 가 `blocked`. F-2 전용 때
  DDL·코드·Neon 을 같이 옮긴다.
- **남은 것**: ngrok authtoken·고정 도메인(사용자 계정) → 터널 기동 → basic auth 무료 여부 확인 → 조서희에게 주소·
  사용법 전달. 조서희 쪽 걸림돌 하나 — 서버는 `segment_id` 를 정수로 보내는데 프론트 파서가 문자열만 받아
  전사를 버린다([미결](/open-items/)). `python-dotenv` 가 `.venv` 에 없어 `uvicorn --env-file` 이 죽었다 —
  `server/requirements.txt` 에 넣었다.
