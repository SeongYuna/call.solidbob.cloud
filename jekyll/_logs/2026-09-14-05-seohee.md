- **블랙리스트 신규/기존(재범) 분류 + 등록일 표시** — 관리자 화면 블랙리스트 탭에
  `[전체] [신규] [기존(재범)]` 필터를 추가했다. "기존(재범)" 기준은 사용자에게
  두 안(재등록 여부 vs 최근 등록일 기준)을 먼저 제시해 재등록 여부로 정했다 —
  같은 customer_ref로 다른 등록 이력(해제된 것 포함)이 있으면 재범이다. 각 행에
  등록일(`approved_at`)도 만료일 옆에 추가했다.
- **검증 과정에서 임시 구글 로그인 우회를 넣었다 뺐다** — admin 앱에 Google
  OAuth 게이트가 이미 있어 로컬에 Client ID·Redis·서버가 없으면 화면 자체를
  못 봤다. `App.tsx`에 `VITE_DEV_SKIP_AUTH`(dev 빌드에서만 동작, 프로덕션
  번들에서 dead-code로 빠지는 것까지 확인) 임시 우회를 넣어 사용자가 직접
  확인했고, 확인 끝난 뒤 커밋 전에 코드에서 다시 뺐다(약속한 대로 "임시"로
  끝냄 — App.tsx·vite-env.d.ts·index.css 세 곳).
- **같은 세션에서 게이트웨이 502도 고쳤다** — ngrok이 8080으로 정상 포워딩
  중인데 게이트웨이 프로세스 자체가 안 떠 있었다(`npm install`만 하고
  `npm start`를 안 돌렸었음). 로컬 `/health`·`/dev` 200 확인 후 공개 ngrok
  주소로도 200 확인했다.
- 백로그 티켓: `w4-blacklist-new-vs-repeat`.
- 남은 것: 없음 — 세 건(블랙리스트 분류·로그인 우회 검증·게이트웨이 502) 모두
  이 세션에서 완결.
