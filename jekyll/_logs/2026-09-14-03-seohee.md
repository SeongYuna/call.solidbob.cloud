- **`main` → `frontend` 동기화**: 오늘 커밋(rename·관리자 로그인) 먼저 마치고, `origin/main`을
  받아 `frontend`에 머지 후 푸시했다. `origin/main`이 이미 `origin/frontend`를 전부 포함하고
  있어서(정성윤 님이 인프라 쪽에서 메인으로 동기화해 둔 상태) main 하나만 받으면 됐다.
  충돌 6개(`.env.example`·`docs/harness.md`·`open-items.markdown`·`services/gateway/*` 3개)를
  풀었다 — `services/gateway`는 정성윤 님이 09-11에 만든 진짜 게이트웨이(Google STT 스트리밍,
  TS 클린 아키텍처)로 완전히 교체됐고, `open-items.markdown`에 나(조서희)에게 남긴 정확한
  머지 지침("main 쪽을 고른다")과 일치해서 그대로 따랐다. `cd server && pytest`·
  `apps/admin`·`apps/call` typecheck 전부 통과 확인 후 푸시(`d6efaaa`).
- **`?gateway=` 런타임 오버라이드 보안 구멍을 고쳤다** — 머지로 딸려온 `open-items.markdown`
  항목이 지적한 것으로, `ws://`·`wss://`로 시작하기만 하면 아무 주소나 받아 저장하던 걸
  운영 번들에서 실제로 확인했다고 적혀 있었다. `isAllowedGatewayUrl()`로
  `wss://server.solidbob.cloud/gateway/*`와 로컬(`ws://localhost`·`ws://127.0.0.1`)만 허용하고,
  `GatewayOverrideBanner.tsx`로 오버라이드가 켜진 동안 화면에 주소+해제 버튼을 띄운다.
  Node로 서브도메인 스푸핑 케이스까지 포함해 허용 목록 로직을 직접 검증했다.
  `jekyll/open-items.markdown`·백로그 티켓(`w4-gateway-override-allowlist`) 갱신.
