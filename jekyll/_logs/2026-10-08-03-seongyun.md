- **조서희 님 화면 문구 티켓을 넘겨받아 끝냈다**(`w8-agent-screen-plain-copy` done, 담당 조서희 → 정성윤).
  `apps/` 는 조서희 전담이지만 **PM 지시로 가져왔다**(`CLAUDE.md` §0). 문구 선택은 프론트 판단이라 **되돌리거나 다시 써도 된다**고 티켓에 적었다.
  - **들여다보니 문구만의 문제가 아니었다.** 코드를 따라가 보니 셋으로 갈렸다 —
    ① 자물쇠 「민감정보가 마스킹되었습니다」는 **운영에서 아예 안 뜬다**(`piiMatches` 는 `!isCoreApiConfigured()` 일 때만 찬다 — mock 전용).
    ② **「⚠ 경고」 배지는 뜬다** — `hasAlert = item.masked.length > 0` 이라 **개인정보 구간이 있으면 무조건**.
    ③ `.masked-span` 빨간 강조가 **원문을 감싼다** — `*****` 를 덮던 색인데 이제 번호 위에 얹힌다.
  - **②③ 이 시연 영상 검토(10-02) 지적 ③ 의 정체였다** — 「⚠ 경고」가 상담원 위반과 같은 빨간 배지라, **고객이 번호를 불렀을 뿐인 줄**에 붙어 「고객이 잘못했다」로 읽혔다. 빨간 강조는 **번호로 눈을 끌었다.**
  - 고친 것: **「⚠ 경고」 → 「저장 시 가림」**(중립색 `.alert-pill.is-mask`, title 「저장·전송할 때 이 부분은 가려집니다」) · `.masked-span` 기본색을 **중립 회색 + 점선 밑줄**로 · 자물쇠 문구 · `MaskedText.tsx` 의 **거짓이 된 주석**(「실서버는 원문을 절대 주지 않는다」) · `maskSensitiveText.ts` 에 「mock 전용」 한 줄 · `.claude/rules/call.md §2`(옛 문장은 긋고 남겼다, 절대 원칙 8).
    ⚠ mock 의 `.is-pii`·`.is-abuse` 는 **「이미 가려진 자리」라 그대로 뒀다** — 서버가 주는 `masked` 와 뜻이 다르다.
  - 검증: `tsc --noEmit` 통과 · `npm test` **92건**(기존 87 + 새 5). 새 테스트 `test/plainScreenCopy.test.tsx` 는 **소스를 직접 읽어** 옛 문구가 되살아나는지 본다 — 손으로 적은 목록끼리 맞추면 또 갈라지기 때문이다(`ai` 쪽에서 09-22 에 겪었다).
  - ⚠ **운영 화면에서 눈으로 보지는 않았다** — 배포 뒤 확인이 남는다.

- **F-3 브리핑은 서버 쪽만 운영에서 봤다**(티켓은 `in-progress` 그대로). `GET /hub/calls/shoot1-stt3/briefing` 이

  **`source: "rule"` 이 찍힌 것이 핵심** — 모델 범주 판정 0/9 라 규칙으로 되돌린 `decisions/220` 결론이 운영에서 그대로다.

- ⚠ **C-6 베타 운영 확인은 못 했다 — 막혔다.** 완료 조건 3(실서버 `dev_page` 로 덮개 확인)을 하려면

  **운영 기능 플래그 쓰기**라 자동 승인에서 거부됐다. 우회하지 않았다. **켤지 말지는 사용자 판단이다** —
  켜면 폭언 감지 때 **상담원 PC 에서 안내 음성이 난다**(고객에게는 안 들린다 — 송출 경로 없음, `w8-c6-intervention-telephony`).
