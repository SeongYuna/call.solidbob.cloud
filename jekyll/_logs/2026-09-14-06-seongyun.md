- **테스트 음성 업로드·보관(A-6)을 구현했다** — [w4-audio-upload-store](/backlog/w4-audio-upload-store/) 를
  `in-progress` 로 옮겼다. 09-14-04 기록에서 정한 `decisions/110` 의 구현분이다.
  `server` 203 통과 · 계약 4종 KEPT.
- **파드 자격증명 문제가 닫혔다 — 추가 자격증명이 필요 없다.** 운영 파드에서 IMDSv2 로 확인:
  「토큰 발급 성공 → 역할: `callguard-ec2-role`」. hop limit 인상도 전용 IAM 사용자도 불필요하고,
  `decisions/108` ③(AWS 정적 키 제거)을 되돌리지 않는다. `server-env` 에 넣는 것은 넷뿐이고
  **비밀은 `UPLOAD_TOKEN` 하나**다.
  - ⚠ **내가 처음 준 확인 명령이 틀렸다.** IMDSv1 방식(토큰 없이 GET)이라 `401` 이 났는데,
    그건 「막혔다」가 아니라 **IMDSv2 강제**라는 뜻이었다 — 401 이 왔다는 것 자체가 요청이 IMDS 에
    **닿았다**는 증거다(막혔으면 타임아웃). 보안상으로는 좋은 설정이라 그대로 둔다.
- **위치를 `server/apps/uploads/` 에서 `server/apps/hub/` 로 바꿨다**(`110` 에 날짜 붙여 정정).
  `masking`·`blacklist` 는 **HTTP 가 없는 규칙 스포크**이고 라우터는 전부 `hub` 에 있다
  (`server/CLAUDE.md` §2, 실측). 업로드는 판정이 아니라 요청 경로라 `hub` 수직 슬라이스가 맞다.
  새 root package 가 없어 `.importlinter` 의 `root_packages`·`containers` 는 안 건드렸고,
  대신 **계약 3 에 `boto3` 를 금지 목록으로 넣었다** — `hub.app` 은 S3 를 모른다.
- **presigned POST 를 쓴다(PUT 이 아니다).** POST 정책에만 `content-length-range` 를 걸 수 있어
  **크기 상한을 S3 가 실제 바이트로 강제**한다. PUT 은 못 걸어 링크 하나로 무제한 업로드가 된다.
  상한은 인터랙터에서 한 번, S3 정책에서 한 번 — 두 겹이다(브라우저가 거짓 크기를 보내도 막힌다).
- **문은 fail-closed 다.** `UPLOAD_TOKEN` 이 없으면 열리는 게 아니라 **503 으로 잠긴다**.
  「브라우저에 AWS 키가 없으니 안전」은 불충분하다 — **잠기지 않은 presign 발급 지점은 익명 업로드
  프록시**라 막으려던 시나리오가 그대로 재현된다. 게이트웨이(`decisions/109`)와 같은 원칙이다.
- **테스트가 내 버그를 하나 잡았다.** `secrets.compare_digest` 는 **비-ASCII `str` 에 TypeError** 를 낸다 —
  헤더는 latin-1 로 디코드되므로 `0xE9` 같은 바이트가 실제로 들어올 수 있고, 그러면 401 이 아니라
  **500** 이 났다(= 문이 깨졌다는 신호를 공격자에게 준다). 바이트 비교로 고쳤고, **되돌리면 그 테스트가
  실제로 실패하는 것까지 확인**했다.
- **클라이언트가 준 경로를 쓰지 않는다.** 키는 서버가 만든다 —
  `uploads/<날짜>/<무작위 8>-<정규화한 이름>`. `../`·`/etc/passwd`·`datasets/원본.wav` 를 넣어도
  이름 한 조각으로 눌린다(테스트로 고정). 같은 버킷에 AI Hub 원본이 살고 **버킷 버전 관리가 꺼져 있어
  덮어쓰면 복구할 수 없다**(런북 5-1) — 무작위를 앞에 두는 이유다.
- **팀원이 쓰는 법**: `https://server.solidbob.cloud/hub/uploads/page` 를 열고 토큰을 붙여 넣는다.
  페이지에는 비밀이 없고(테스트로 고정), 토큰은 `sessionStorage` 에만 남는다(탭을 닫으면 사라진다).
  파일 바이트는 **서버를 지나가지 않는다** — 브라우저 → S3 직접이라 파드에 음성이 남지 않는다(SEC-1).
- **`newTag` 를 `0.1.5` 로 올렸다**(`server/` 를 고쳤다). ⚠ 내 작업 트리가 `0.1.3` 이라
  **main(`0.1.4`)과 머지할 때 이 줄이 충돌한다 — `0.1.5` 로 살린다.** 다른 세션이 태그를 안 집는 것을
  확인하고 잡았다.
- 남은 것 — **셋 다 사람이 해야 한다**:
  - **버킷 CORS 규칙**(콘솔 → S3 → `assist-apne2` → 권한 → CORS). 오리진은
    `https://server.solidbob.cloud` 하나, `*` 금지. **없으면 브라우저 업로드가 100% 막힌다**
  - **`.env.example` 에 키 넷** — 자격증명 보호 훅이 이 파일 편집을 막는다(`server/CLAUDE.md` §6)
  - **운영 `server-env` 에 `S3_BUCKET`·`UPLOAD_TOKEN`** (`openssl rand -hex 16`) + `0.1.5` 배포 후 확인
- ⚠ **PM 브랜치가 main 보다 14 커밋 뒤처져 있다.** `main.py`·`core/config.py`·`requirements.txt`·
  `test_connection.py` 가 main(#73 관리자 로그인)에서도 바뀌어 **머지 때 작은 충돌이 난다.**
  전부 양쪽이 «끝에 덧붙인» 모양이라 둘 다 살리면 된다.
