- **프론트 페이지가 기대하는 기능을 백엔드에서 전부 점검하고, 서버에서 만들 수 있는 것을 만들었다** — `apps/call`·`apps/admin` 은 실시간 전사·추천 카드·관리자 로그인만 서버에 붙어 있고 나머지는 mock 이었다. 프론트 수정은 조서희 님 몫이라 계약만 넘기고(미결 「조서희 님께 — 대시보드가 받아야 할 계약」), 백엔드를 먼저 채웠다. Neon 스키마 맞추기는 사용자 지시로 제외했다.
  - **C-6 콜 가드 배선** ([w4-call-guard-wiring](/backlog/w4-call-guard-wiring/)) — `ai/apps/call_guard` 를 합성 루트에서 꽂고 `POST /hub/call-guard-checks` → `call_guard_flag` 저장. 게이트웨이가 고객 확정 발화마다 마스킹본으로 부른다
  - **통화 목록** ([w4-call-list-api](/backlog/w4-call-list-api/)) — `GET /hub/calls`(최근순, `customer_id` 필터)
  - **고객 식별 + 블랙리스트 API** ([w4-blacklist-api](/backlog/w4-blacklist-api/), `decisions/304`) — 세 가지를 사용자에게 물어 정했다: 발신 번호는 통화 시작에서 받아 곧바로 HMAC(`caller_phone`, 게이트웨이는 `X-Caller-Phone` 헤더) · 요청자는 `agent_id` 입력 · 승인자는 관리자 로그인 + 새 컬럼 `admin_account.agent_id` · 만료는 승인 때 일수 필수. 요청·목록·승인/반려·등록 목록·해제 5개 경로. 근거·자막은 서버가 DB 에서 모으고 사유·메모는 저장 전 마스킹
  - **콜 가드 로그** ([w4-call-guard-flag-list](/backlog/w4-call-guard-flag-list/)) — `GET /hub/call-guard-flags`(관리자)
  - **F-2 필요서류 체크리스트 재구축** ([w4-required-docs-checklist](/backlog/w4-required-docs-checklist/), `decisions/305`, `w4-schema-qa-followup` ③) — 금융·쇼핑 게이트를 걷고 `TERM.md` 필요서류 조항 35개 중 **조건 없는 25개**를 규칙화(나머지 10개는 `EXCLUDED` 에 이유). 판정 `complete/incomplete` · 조건부 서류는 `conditional` 로만. **자동 판정까지**(사용자 선택): 게이트웨이가 추천 1순위 조항을 절차로 잡고 상담원 확정 발화 키워드로 `POST /hub/required-docs-checks`. 스키마 `closure` 헤더 + `closure_item`
  - 수동 검색은 `/hub/search` 가 이미 있어 코드 없이 계약만 올렸다(`plan.md` 7.3절 끝 「허브 HTTP 표면」)
- **E2E 로 버그 둘을 잡았다** — 로컬 postgres:17 + 서버 + 게이트웨이를 띄워 `/dev/text` 로 관통했다. ① **`call_guard_flag.source_doc_id` 가 `document` 를 참조하는데 그 테이블을 채우는 경로가 없어**, 실제 탐지기가 근거 조항을 붙이면 저장이 23503 으로 통째로 실패했다(내 integration 테스트는 조항 없이 넣어서 못 봤다) — 조항이 있을 때만 잇도록 고치고 테스트를 실제 조항으로 바꿨다 ② `GET /hub/calls` 의 `customer_id` 필터가 옛 길이 40 이라 64자 HMAC 이 422 — 고쳤다. 확인한 것: 발신 번호 → 64자 식별자, 전사·고객·요청 어디에도 평문 번호 0건, 사유 번호 마스킹, 필요서류 판정이 헤더+항목으로 저장
- **확인한 것**: server `pytest` 626 통과 / 13 스킵 · integration 10 통과(로컬 `postgres:17` 에 현재 `schema.sql`) · 계약 4 유지 · ai 195 통과 / 13 스킵 · 계약 3 유지 · gateway typecheck + 101 통과. 이미지 태그 server `0.1.5` · gateway `0.1.3`. 규칙표는 조항 원문에 서류 이름이 있는지 대조하는 테스트를 붙였다
