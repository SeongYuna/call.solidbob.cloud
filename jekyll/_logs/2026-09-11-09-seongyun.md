- **게이트웨이(A-1~A-4)를 만들었다 — `services/gateway`, 3주 동안 코드 0줄이던 「필수」 블록이다.**
  기획서 역할표(`plan.md` 7.1절)와 `decisions/019` 가 정성윤 몫으로 적어 뒀는데 **티켓이 한 번도 없어서** 칸반에
  안 보였다. 시작할 때 티켓부터 만들었다([w4-gateway-streaming-stt](/backlog/w4-gateway-streaming-stt/)).
- **모양**: 오디오 생산자 → `WS /ingest`(PCM16, **연결 하나 = 화자 하나**) → Google STT 스트리밍 → server
  (`POST /hub/calls` → `/hub/transcripts` → final 이면 `/hub/recommendations`) → `WS /ws` 로 대시보드에.
  대시보드는 받기만 한다는 것을 `realGatewayClient.ts` 에서 확인하고, 그 파서가 이미 기다리는 `{type, payload}` 형식
  그대로 보낸다. 서버 응답을 그대로 흘리므로 «값은 전부 문자열» 계약(09-10)도 따로 맞출 게 없다.
- **SEC-1** — 원문은 게이트웨이 → server 로만 간다. **server 가 실패하면 그 결과는 아무 데도 안 간다.** 로그엔 번호·상태
  코드만 남기고, 422 본문(원문을 되돌려 준다)은 읽지 않고 버린다. 테스트로 고정했고, 원문을 흘리게 일부러 바꾸면
  그 테스트가 실패하는 것까지 봤다.
- **COST-1** — 장부를 `scripts/transcribe_batch.py` 와 **같은 파일·같은 형식**(`data/processed/stt-usage.json`)으로 쓴다.
  배치와 달리 **캡이 비어 있으면 막는다(fail-closed)** — 스트림은 끝을 몰라서다. 캡을 넘겼으면 새 채널을 안 열고,
  열린 채널도 캡에 닿으면 거기서 끊는다. **실제 장부로 둘 다 확인했다** — 캡 10초 인스턴스에서 장부가 9.95초에서 멈췄다.
- **실제 구글로 관통했다** — AI Hub 음성 2.8초(`resources/0001.wav`, gitignore 대상)를 실시간 속도로 흘려 final 까지
  대시보드 채널에 도착했다. 스테레오(같은 음성을 좌·우에)로 두 채널도 봤다 — 발화 번호가 통화 안에서 `#1 customer`·
  `#2 agent` 로 이어지고 통화 시작은 한 번만 갔다. 오늘 쓴 STT 는 15.6초 / 600초.
- **관통에서 내 결함 둘을 찾아 고쳤다.** ① **interim 이 조각나 서로 덮어썼다** — 구글은 응답 하나에 «안정된 앞부분 /
  흔들리는 뒷부분»을 결과 여러 개로 나눠 보내는데 조각마다 따로 흘려, 화면에 뒷조각(" 쓰고 다른")만 남았다. 이어 붙여
  한 결과로 낸다. 실측 모양 그대로 테스트를 만들었고 옛 동작으로 되돌리면 실패한다. ② **`/health` 가 기동 직후 사용량을
  0 으로 보고했다** — 장부를 첫 채널 때만 읽었다. 기동 때 읽는다.
- **⚠ 못 본 것 둘** — ① **추천 카드가 화면까지 가는 것**: 이 머신에 ES 가 없어(docker 데몬 없음) 서버가 500 을 냈다.
  트리거 발동까지는 확인했고, 상담원 발화의 `fired:false` 는 대시보드 채널까지 왔다. ② **DB 저장**: 첫 관통에서 final
  저장이 500 이었는데 원인은 게이트웨이가 아니었다 — 로컬 서버가 bc 세션의 미커밋 복합키 upsert 코드로 떠 있었고
  Neon 은 09-09 이전 DDL 이다. 그 세션에 알렸고(원인 확인 답을 받았다), 이후 관통은 서버를 DB 없이(로그 어댑터) 띄워 했다.
  게이트웨이가 통화마다 `segment_id` 를 1부터 세므로 **그 복합키 수정에 기대고 있다**.
- **CI `gateway` job 을 붙였다.** 다른 세션의 server job 변경과 같은 파일이라 끝에 덧붙이기만 했다. `| tee` 가 실패를
  삼키는 문제(a5 세션이 짚었다)는 `set -o pipefail` + 실패 개수 검사 두 겹으로 막았고, step 본문을 뽑아 `bash -e` 로
  돌려 실패 테스트가 있으면 `exit=1` 인 것까지 봤다. **아직 main 룰셋의 필수 통과 검사가 아니다.**
- **`.env.example` 은 넣지 않았다** — 새 키 둘(`GATEWAY_PORT`·`CORE_API_URL`)이 필요한데 자격증명 보호 훅이 파일 이름으로
  막는다. 우회하지 않고 [미결](/open-items/)에 올렸다. 모노 diarization·배포·ES 500 도 거기 적었다.
