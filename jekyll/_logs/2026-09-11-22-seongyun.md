- **`.env.example` 에 게이트웨이 키 넷을 넣었다** — `GATEWAY_PORT` · `CORE_API_URL` · `GATEWAY_INGEST_TOKEN` · `GATEWAY_VIEW_TOKEN`.
  값 없이 키 이름과 설명만이다(기본값·fail-closed·운영은 `gateway-tokens` 시크릿이 만든다는 것까지). 설명은
  `services/gateway/src/{config,main}.ts`·`domain/access.ts` 와 대조했다. 자격증명 보호 훅이 이 파일을 막아 **Claude 가 블록을 스크래치에
  만들고 사용자가 `!` 로 붙였다**(훅은 우회하지 않았다). 추가 뒤 중복 키 0 · 값이 든 줄 0 을 확인했다.
  - 코드가 읽는데 예시에 없던 키를 전부 대조했다(server·ai·scripts·gateway). 나머지 둘(`CALLGUARD_SKIP_SESSION_CHECK` ·
    `USER`)은 앱 설정이 아니라 넣지 않았다. `CALLGUARD_TEST_DATABASE_URL` 은 pytest 가 `.env` 를 읽지 않아 셸에서 준다(`server/CLAUDE.md` §4).
- **「추가로 넣어야 할 env」를 운영·Vercel·로컬까지 봤다.**
  - 운영 서버 CORS: `https://call.solidbob.cloud` 사전 요청이 **400**(서버 `server-env` 에 `CORS_ALLOWED_ORIGINS` 없음). 게이트웨이는
    `gateway.yaml` 에 이미 허용해 뒀다.
  - **정정** — 처음엔 서버 CORS 를 「가장 급하다」고 안내했는데 틀렸다. 대시보드는 서버를 직접 부르지 않는다 —
    실시간은 전부 게이트웨이 WebSocket 이고, `VITE_CORE_API_URL` 은 헤더 `REST` 배지만 켠다(통화 기록은 아직 mock).
  - 로컬 `.env`(키 이름·빈 값 여부만 봤다): `DATABASE_URL` 이 쓰지 않기로 한 Neon 을 가리키는 것으로 보인다 — 사용자에게 알렸다.
- **대시보드를 라이브로 바꾸는 Vercel 설정은 일부러 멈췄다.** 절차를 안내하다 확인해 보니, 미결 「뷰 토큰을 대시보드에 어떻게 줄지」가
  아직 열려 있고, 대시보드는 조서희 님 전담이며(`302` · `109`), 바꾸면 공개 데모가 mock 에서 **빈 화면**(오디오 생산자 없음)이 되고
  뷰 토큰이 공개 번들에 들어간다. 선택지 A(mock 유지 + `?gateway=`) · B(Vercel) · C(화면에서 토큰 입력)를 [미결](/open-items/)에
  정리하고 **A 를 권고**했다. 브라우저에서만 해 보는 `?gateway=` 시험은 괜찮다고 안내했다.
  - 사용자가 curl 로 뷰 토큰 접속을 확인하다 `000` 을 받았다 — 여기서는 토큰 없음·틀린 토큰 모두 `401` 로 닿았고, 101 을 주는 가짜 서버로
    curl 8.5 가 101 을 찍는 것도 확인했다. 그래서 `000` 은 응답을 못 받은 것(주소에 `< >` 가 남는 등)으로 보고 `-sS` + 종료 코드로
    원인을 보게 안내했다. **실제 원인은 확인하지 못했다.**
- 남은 것: A/B/C 결정(조서희·정성윤) · 서버 CORS 는 통화 기록이 REST 로 바뀔 때 · `.env.example` 의 `DATABASE_URL` 주석에 RDS `sslmode=require`
  한 줄(사람이 넣는다) · 로컬 `.env` 의 DB 를 로컬 PostgreSQL 로.
