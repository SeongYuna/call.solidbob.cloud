- **합성 통화를 상담원 대시보드에서 실제 대화처럼 보이게 했다 — 프론트(`apps/`)는 고치지 않았다.** 대시보드는 이미 게이트웨이 `/ws` 의
  자막·추천·콜 가드·필요서류 메시지를 그리므로, 대본을 게이트웨이에 흘리는 **재생기**만 만들었다.
  `services/gateway/scripts/replay_persona_call.ts` — 두 채널(`/dev/text?producer=script`)로 부분 결과를 어절째 늘려 보내고 확정한다.
  `--speak` 는 이 맥의 `say` 한국어 음성으로 소리를 낸다(무료). 계획 함수는 `scripts/persona_replay/plan.ts` + 테스트 5
- **게이트웨이 본체 두 가지** (`0.1.6`으로 올림 — `tag-check` 가 필수 검사라 태그 없이는 머지가 안 된다):
  ① `/dev/text` 도 `X-Caller-Phone` 헤더를 받는다 — 없으면 SYN-006(블랙리스트 요청) → SYN-007(베테랑 배정)이 같은 고객으로 안 이어진다
  ② `producer=script` 면 `call.stt_engine` 을 `synthetic-script` 로 적는다 — 모르는 값은 `web-speech` 로 쳐서 호출자가 엔진 이름을 지어 넣지 못한다
- **검증**: 게이트웨이 테스트 **107 통과**(새 2건 포함) · `tsc` 통과 · `check_release_tags.py` 통과(server 0.1.13 그대로, gateway 0.1.6 레지스트리에 없음).
  실제 게이트웨이 코드 + 가짜 허브로 SYN-006 을 끝까지 재생 — 전사 72건(부분 60 · 확정 12), 두 화자, 엔진 `synthetic-script`, 발신 번호 전달 확인.
  **실서버·운영 대시보드 화면으로는 보지 않았다** — 머지·배포 뒤 할 일이다
