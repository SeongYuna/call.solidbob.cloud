- **운영 DB 가 옛 스키마라는 것을 확인하고, 데이터를 보존하는 변경 SQL 을 만들어 검증했다** — 「스키마 들어가 있다」 는 말을 받아 운영 서버 파드에서 조회해 보니 `call.customer_id` 40자 · `admin_account.agent_id` 없음 · `closure_item` 없음. 더 보니 **테이블 22개로 `fd96adc`(09-09) 상태이고, 관리자 로그인 테이블(`admin_account`·`admin_refresh_token`)도 없었다** · `closure` 0건. 운영 조회는 사용자가 인스턴스에서 쳤다(이 머신엔 AWS 자격증명이 없다).
