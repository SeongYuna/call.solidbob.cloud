- **대시보드 마스킹 시나리오에 권한 확인 후 원문 토글을 이식했다.** `c_dasan_ko_masking` 대사에 `text`(마스킹)/`plain_text`(가상 원문) 쌍을 넣고, 실시간 자막 헤더에 「권한 확인 (데모)」·「원문 보기」를 두었다. 권한 전에는 스팬·⚠ 경고가 반응하지 않고, 확인 뒤에는 스팬별 토글·전체 토글·배지 토글이 된다. 열람 시 콘솔에 `[열람 기록]` mock을 남긴다. `apps/platform`은 손대지 않았다.
- 연락처 마스킹은 `***-****-****`가 아니라 원문과 같은 길이의 `*************`다. 대시 끼운 별표는 `asteriskSpan`이 첫 `*` 구간만 잡고, 글자 수도 `010-2345-6789`와 어긋나 복원 슬라이스가 깨진다.
- 확인: `apps/dashboard` `npm run typecheck` 통과. 마스킹/원문 세 쌍 코드포인트 길이 일치. 브라우저 자동화는 이 환경에 없어, 로컬 `5173`에서 상담기록 「민원 접수 본인확인」 재생으로 클릭 경로는 직접 확인이 남는다.
- 남은 것: 상담기록 요약 화면에는 `TranscriptPanel`이 없어서, 열람 UI는 통화 재생(어시스트)에서만 보인다.
