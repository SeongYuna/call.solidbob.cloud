- **이미지 2종을 Docker Hub 에 올리고 k3s 매니페스트를 만들었다.** `seongyuna/callguard-server:0.1.0`
  (362MB) · `seongyuna/callguard-es:9.5.1`(2.58GB), 둘 다 public 이라 k3s 에서 `imagePullSecret` 이
  필요 없다. **저장소를 미리 만들 필요가 없었다** — push 가 곧 생성이다.
- **nori 를 목록이 아니라 동작으로 확인했다.** `_cat/plugins` 에 `analysis-nori 9.5.1` 이 뜨는 것에
  더해 `_analyze` 로 쪼개 봤다 — 「전입신고에 필요한 서류를 알려주세요」가 nori 로는
  `전입·신고·필요·서류·알리·주`, 기본 분석기로는 `전입신고에·필요한·서류를·알려주세요` 다.
  조사가 붙은 채로 토큰이 되면 「전입신고 서류」로 물었을 때 안 걸린다 — BM25 품질이 여기서 갈린다.
  「외국인등록증하고 여권 사본」도 `외국·인·등록·증·여권·사본` 으로 갈렸다(`여권` 은 다산 서류 문의 4위 단어다).
- **`infra/k8s/` 를 만들었다** — `base/`(운영) + `local/`(리허설), kustomize. **RDS 독립 사용 기준이라
  클러스터 안에 PostgreSQL 이 없다.** 접속 정보는 `db-credentials` 시크릿으로만 들어가고,
  `secret.example.yaml` 은 키 이름만 담아 `resources:` 에서 일부러 뺐다(SEC-2).
- **로컬 k3s 에서 실제로 돌렸다.** 파드 2개 Running, 클러스터 안에서 서로 부른 결과 —
  `{"status":"ok","postgres_configured":true,"elasticsearch_configured":true,
  "spokes":["masking","closure_gate","retrieval"]}` · `/docs` 200.
  `POST /hub/search` 는 **500 `index_not_found_exception [callguard-kb-single]`** 인데
  **이게 좋은 신호다** — 연결 오류가 아니라 ES 가 돌려준 오류라, server→ES 왕복이 실제로 된다는 뜻이다.
  인덱스 적재(`index_knowledge_base.py --to-es`)가 아직 안 됐을 뿐이다.
- **컴포즈를 가리키던 살아 있는 문서 3곳을 고쳤다** — `README.md`(구조표. `terraform/` 이 있다고
  적혀 있었는데 그것도 없다) · `scripts/index_knowledge_base.py` 독스트링 · `docs/06` 재현 명령.
  옛 결정 기록·백로그·STATE-archive 는 **그 시점의 사실이라 고치지 않았다**(절대 원칙 8).
- 남은 것: **EC2·RDS 가 아직 없다.** 이 머신에 AWS 자격증명도 없어서(`aws sts get-caller-identity`
  실패) 콘솔 작업은 사람이 해야 한다. **GPU 할당량 증설 요청이 승인에 하루 걸리므로 그것부터** 건다.
  그리고 로컬 k3s 는 traefik 이 살아 있다 — EC2 에는 `--disable=traefik` 으로 설치해야 Caddy 와 안 부딪힌다.
