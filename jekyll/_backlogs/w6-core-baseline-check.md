**시한 있는 조건이 상시 금지로 읽혀 확장 논의가 6건 멈췄다**(`decisions/022`).

## 무엇을 보고 판정하는가

- **B(검색)** — Recall@5 ≥0.70(오류 없음) / ≥0.60(오류 10%)
- **C-5** — 누락 **0건**. ⚠ **잰 범위 안에서만 성립한다** — 표본 0건인 패턴은 「통과」가 아니라 **「측정 불가」**다
- **E** — 하네스가 실제로 돌고 값에 측정일·커밋·명령·표본 수가 붙어 있다(§5)
- **여러 번 실행한 값 중 최저치**로 고정한다(절대 원칙 4)

## 게이트를 켜는 것과 수치가 나온 것은 다른 결정이다

`STATE.md` 가 적어 둔 그대로다 — 절대 원칙 5(미달 시 CI 실패)를 켜면
미구현 항목 때문에 계속 빨간불이 된다. **무엇을 게이트에 넣고 무엇을 「측정 불가」로 둘지**를
여기서 정한다. 선행 티켓이 [w2-baseline-gate](/backlog/w2-baseline-gate/)다.

## ⚠ 2026-09-19 — 판정일이 11일 남았는데 **쓸 수 있는 공식 수치가 없다**

판정일은 **6주차 종료 = 2026-09-30**이다(1주차 `08-20~08-26` 기준). 그런데 —

- `STATE.md` 의 실측값 블록은 **2026-09-09 값**이다: `retrieval 0.833/0.659 ✅` · **`masking 누락 2 ❌`** ·
  `closure_gate` 측정 불가 · `trigger`·`compliance` 측정 불가. **지금 판정하면 C-5 절대 규칙 미달로 동결이 걸린다.**
- 그 뒤 2주 동안 들어온 것(dense+리랭커 `0.979/0.919` · NER · C-5 규칙 보강 누락 0 · 컴플라이언스 규칙 v1)은
  **전부 로컬 측정이고 하네스 기록(`eval_run`)이 아니다.** 절대 원칙 2·5 상 그 값으로는 판정할 수 없다.

**그래서 판정 전에 두 가지가 먼저다.**

**① 무엇을 판정 대상 구성으로 삼을지 정한다** — 이게 순서상 먼저다.
운영은 **규칙 + BM25**로 돌고(이미지에 torch 가 없다), 로컬 최고 구성은 **NER + dense + 리랭커**다.
로컬 최고 수치로 「통과」를 선언하면 **운영에서 성립하지 않는 통과**가 된다. `decisions/208`(운영에 NER·임베딩을
올릴지)이 아직 «제안» 상태라 **그 결정이 곧 판정 기준선의 정의**다. 둘 다 재고 **어느 쪽을 기준선으로 고정할지**를 판정문에 적는다.

**② 현재 코드로 하네스를 다시 돌려 기록한다**(`--record` — 커밋·골든셋·표본 수가 함께 남는다).
ES·모델이 필요해 **이 저장소의 윈도 머신에서는 못 돈다** — 류준 님 맥이나 측정 전용 인스턴스(런북 22장) 몫이다.

```bash
docker build -t callguard-es:local infra/elasticsearch/      # 9200 에 띄운다
.venv/bin/python scripts/index_knowledge_base.py --to-es --recreate     # 98조항
ELASTICSEARCH_URL=http://localhost:9200 .venv/bin/python scripts/run_eval.py --runs 3 --record
```

**볼 것**: ① `masking` 이 09-09 의 ❌(누락 2)에서 정말 0 으로 갔는지 ② **`NO_SAMPLES` 가 어디에 남는지** —
골든셋 `v1-150`(156건)에 C-5 표본은 일곱 패턴 다 있지만(P1 4·P2 2·P3 3·P4 5·P5 4·P6 7·P7 3),
**`f2_case` 는 여전히 0건**이라 F-2 는 측정 불가 그대로다(09-19 파일 실측).
