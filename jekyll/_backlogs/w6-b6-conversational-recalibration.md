## 무엇을

`decisions/215` 의 dense 1순위 < 0.67 기권은 **질문형 표본**으로는 통과했지만, 합성 통화 E2E 24건(09-22)에서 **대화체 발화의 60%(114/189)를 기권**시켜 SYN-015·017 의 필요서류 절차를 지웠다. 그래서 보류했다(기본 꺼짐).
맞장구 36건은 전부 걸렀으니 **노린 효과는 있다** — 필요한 카드를 지키면서 그것만 얻는 방법을 잰다.

## 어떻게

1. **대화체 보류 표본을 먼저 만든다** — 합성 대본 24건의 고객 턴을 「필요한 카드가 걸린 턴 / 맞장구·인사 / 정답 없는 문의」로 라벨. 재는 데 쓸 후보를 보기 **전에** 만든다
2. 후보를 **사전 등록** — ① 문턱 재보정 ② 맞장구는 트리거(B-1)에서 억제하고 문턱은 낮게 ③ 앞 발화와 합친 질의 창
3. 한 번 잰다. 채택 조건도 미리 적는다(예: 필요한 카드 손실 0 · 맞장구 기권 ≥ 90%)

## 완료 조건

- [ ] 대화체 표본 파일 + 라벨 근거
- [ ] 사전 등록 → 측정 → 결정 기록(`2xx`) — 채택이든 아니든
- [ ] 채택이면 E2E 24건 재실행으로 대본 단위 회귀 0 을 보인다
