## 2026-09-23 — 확인해 보니 번호 매긴 둘 다 이미 고쳐져 있었다 (조서희)

**1. AgentCallBox가 합성 통화 보기를 가린다** — 오늘 이 세션 앞쪽(`w6-qa-call-screen-fixes`,
커밋 `e922e1e`)에서 이미 고쳤다. `AgentCallBox.tsx`가 `utterances.length > 0`이 되는
순간(대본이든 실제 마이크든, 출처를 안 가린다) 스스로 사라진다 — 재생기가 자막을
흘려보내기 시작하면 모달이 자동으로 걷힌다. 그때는 "통화받기 창이 눌러야만 닫힌다"는
다른 QA 항목을 고치던 중이었는데, 같은 수정이 이 항목도 덮었다.

**2. `customer_id` 해시 노출** — 확인해 보니 09-22에 이미 걷혀 있었다(커밋 `86a3c27`,
"상담기록 목록에서 고객 해시 노출 제거"). `LiveCallHistoryList`(실서버 목록)는 해시를
아예 렌더하지 않고, 같은 목록 안 중복 횟수만 세어 "재문의 고객" 배지로만 보여준다
(`repeatCounts`, `CallHistoryPanel.tsx`). 원본 노출이 남아 있던 `MockCallHistoryList`는
**mock 시나리오 라벨**(`고객 #abc123`류 표시용 문자열)이라 실제 해시가 아니다 — 걱정한
경로가 아니다.

**대기 중이던 둘도 이번에 정했다:**

- **공개 데모를 라이브로 바꿀지** — 이미 결정돼 있었다. `open-items.markdown`의 같은
  질문이 `decisions/127`(2026-09-21)로 "라이브로 둔다"로 이미 닫혀 있다 — 이 티켓이
  09-21에 적은 "권고는 mock 유지"보다 그 결정이 나중이라 그게 이긴다. 새로 결정할 것
  없음.
- **상담기록 목록에 요약 미리보기를 넣을지** — **넣지 않기로 정한다(새 결정, 4xx 아님 —
  되돌리기 쉬운 UI 판단이라 기록만 남긴다).** `GET /hub/calls` 목록 응답에 요약 필드
  자체가 없다(`CallListResponseWire`) — 넣으려면 ① 서버가 목록에 요약을 실어야 하거나
  (서버 쪽 작업, 별도 티켓) ② 화면에서 건마다 `/record`를 따로 불러야 한다(N+1, 50건
  목록이면 호출 50번). 지금은 불필요한 비용이라 미룬다 — 서버가 목록 응답에 요약을
  같이 주기로 하면 그때 다시 연다.
