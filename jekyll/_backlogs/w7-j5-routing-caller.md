## 무엇을

`POST /hub/routing-decisions`(J-5 인입 전 배정 판정, `decisions/313`)는 **만들어져 있고 아무도 부르지 않는다.**
시연에서 부를지, 부른다면 누가 어떤 토큰으로 부를지 정한다.

## 왜 정성윤 몫인가

후보가 콜 미디에이터다 — 통화가 시작되는 순간을 아는 것이 거기뿐이다. 09-15 부터 조서희·장민석 님 로그에
**「정성윤 결정 대기」**로 남아 있다.

## 선택지

- `/dev` 테스트 콜이 통화 시작 직후 부른다 → 쓰기 경로 서비스 토큰([w5-ingest-auth-fail-closed](/backlog/w5-ingest-auth-fail-closed/))을 그대로 쓴다
- 시연에서 부르지 않는다 → API 는 있고 **「인입 전 배정은 전화 사업자 연동이 있어야 의미가 있다」**를 발표에 그대로 적는다

## 완료 조건

- [ ] 결정을 `_logs/` 에 남기고 조서희·장민석 님 대기를 푼다
- [ ] 부르기로 하면 — 판정 결과가 상담원 화면 어디에 보이는지까지 조서희 님과 맞춘다

## 결정 (2026-09-21, 정성윤) — `_project/decisions/126`

**콜 미디에이터가 통화 시작 직후 부른다. 통화 종료는 미디에이터가 부르지 않는다**(화면 버튼 그대로). 구현은 열쇠 꽂기(`w5-ingest-auth-fail-closed`) 뒤다.

구현할 때 정할 것 — 결정 기록에 그대로 적었다.
- **후보 상담사 목록** — API 는 「지금 받을 수 있는 상담사」를 부르는 쪽이 넘기게 돼 있는데 미디에이터는 누가 대기 중인지 모른다. 시연 범위에서는 미디에이터 설정의 후보 목록으로 넘긴다(비면 빈 목록)
- **발신 번호가 없는 테스트 콜은 늘 「블랙리스트 아님」**이다. J-5 를 보이려면 블랙리스트에 올린 고객 번호로 통화를 시작한다
- 판정이 실패해도 통화는 막지 않는다 · 서버 쪽 서비스 토큰 문은 장민석 님 · 화면 표시 위치는 조서희 님과
