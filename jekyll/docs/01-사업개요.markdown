**StreamRAG : CallGuard** — 서울시 120 다산콜센터를 위한 실시간 상담원 어시스트.
통화를 들으며 **그 절차에 필요한 구비서류를 자동으로 띄우고**, 외국인 고객의 발화를
**한글로 동시 통번역**한다.

> **2026-08-28 방향 전환**(`_project/decisions/201`) — 4개 도메인 지원에서 **다산콜센터
> 하나**로 좁히고, **외국인 고객 지원**을 차별점으로 세웠다. AICC 시장에 대기업이 가득한
> 상황([9절](/docs/09/))에서 4개 도메인을 얕게 지원하는 것으로는 차별점이 없다고 판단했다.
> 국내 체류외국인은 **287만 명**(2026-06-30)이고 정부는 연내 300만을 전망한다.

통화를 실시간으로 들으면서, 고객이 방금 물은 내용에 필요한 사내 문서를 상담원 화면에 자동으로 띄워준다. (rev.4, 작성일 2026-08-24)

## 1.1 투입자원 목록이 이미 답을 가리킨다

제시된 투입자원 중 **Google Speech-to-Text API**와 **WebSocket**은 리뷰 감정 분석 같은 주제에서는 쓸 데가 없다. 이 두 도구가 목록에 있다는 것은 콜센터 주제를 염두에 둔 구성으로 보인다.

| 도구 | 콜센터 주제 | 리뷰 감정 분석 |
|---|---|---|
| Google STT | 필수 | 불필요 |
| WebSocket | 필수 | 불필요 |
| Elasticsearch | 핵심 | 선택 |
| HuggingFace | 활용 | 활용 |

## 1.2 "통화 후" 대신 "통화 중"

흔한 콜센터 프로젝트는 녹음 파일을 사후 처리한다(전사 → 요약 → 티켓 생성). 이는 사실상 **배치 파일 변환 파이프라인**이며 WebSocket이 필요 없다.

본 프로젝트는 **통화가 진행되는 중에 개입**한다.

| | 사후 처리형 | 실시간 개입형 (본 프로젝트) |
|---|---|---|
| 입력 | 완성된 녹음 파일 | 0.3초 단위 스트리밍 조각 |
| 질의 | 완결된 문장 | 미완성 발화 |
| 레이턴시 요구 | 없음 | 1초 이내 |
| RAG 난이도 | 낮음 | 높음 (트리거 판정 + 오류 내성) |
| 제품 범주 | 통화 분석 | Agent Assist |

## 1.3 모듈 우선순위

| 모듈 | 내용 | 우선순위 |
|---|---|---|
| A~E | 실시간 어시스트 코어 | **필수 — 절대 사수** |
| C-5 | 개인정보 마스킹 | **필수 — 코어 포함, 3주차** |
| F-2 | 종결 요건 검증 게이트 | 조건부 (7주차 체크포인트) |
| F-3·F-4 | 반복 처리 연결 / 감사 로그 | 여유 시 |
| G-2 | 지역 자원 연계 검색 | 여유 시 |
| H·I | [부록 B](/docs/13/) | 코어 완료 시 택1 |

> **F 모듈은 코어와 같은 업무 도메인 안에서 설계한다.** 이전 리비전은 F 모듈을 실종신고 접수·종결(공공기관 업무)로 설계했으나, 코어와 재사용 가능한 것이 거의 없어 두 번째 지식베이스·데이터모델·화면·골든셋이 필요했다. rev.4는 F-2를 **종결형 처리(해지·환불 등)의 요건 검증**으로 옮겨 코어와 같은 ES 인덱스·`call` 테이블·대시보드·골든셋을 그대로 쓴다.

## 1.4 데모 도메인 — 실제 확보 데이터 4종으로 한정 (2026-08-26)

가상 통신사 "한별텔레콤" 단일 시나리오는 폐기했다. **실제로 신청·확보한 데이터가
통신 도메인에는 없고**, AI Hub 「민원(콜센터) 질의-응답」데이터셋 기준 4개 도메인에만
존재하기 때문이다. 이 4개 도메인을 전부 지원하는 것으로 범위를 한정한다 — 그 이상도
이하도 아니다.

| 도메인 | 가상 주체 | 실측 카테고리 | F-2(종결 요건 검증) |
|---|---|---|---|
| 금융보험 | 한별금융 | 사고 및 보상 문의 · 상품 가입 및 해지 · 이체출금대출서비스 · 잔고 및 거래내역 | 적용 (상품해지·보상) |
| 다산콜센터 | 한별시 통합민원콜센터 | 대중교통 안내 · 생활하수도 관련 문의 · 일반행정 문의 · 코로나19 관련 상담 | 미적용 (안내형 업무) |
| 쇼핑 | 한별샵 | 주문 · 결제 · 배송 · 교환 · 반품 · AS · 업무처리 | 적용 (반품·교환) |
| 질병관리본부 | 한별헬스콜 | 건강질병 · 기타문의 · 약품식품 · 온라인신고 · 요양기관 현황 · 증상징후 · 진료비정보 | 미적용 (안내형 업무) |
