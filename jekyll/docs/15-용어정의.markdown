| 용어 | 정의 |
|---|---|
| **Agent Assist** | 상담원과 고객 사이의 대화를 실시간으로 분석해 상담원에게 정보·경고·추천을 제공하는 제품 범주. Amazon Q in Connect, Google Agent Assist 등이 대표 사례 |
| **STT (Speech-to-Text)** | 음성을 텍스트로 변환. 본 프로젝트는 Google STT의 스트리밍 모드(부분 결과 포함)를 사용 |
| **화자 분리 (Diarization)** | 통화 오디오에서 "누가 말했는지"(고객/상담원)를 구분하는 것. 2채널 스테레오 녹음이면 채널 분리로 대체 가능 |
| **트리거 판정** | 스트리밍 전사 중 "지금 검색해야 하는 시점"을 결정하는 로직. [4.1절](/docs/04/) |
| **하이브리드 검색** | BM25(형태소 기반) + dense_vector(임베딩 기반) 검색을 함께 수행하고 결과를 병합하는 방식 |
| **nori** | Elasticsearch의 한국어 형태소 분석 플러그인. 띄어쓰기 오류를 흡수하는 데 사용 |
| **RRF (Reciprocal Rank Fusion)** | 여러 검색 결과(BM25, 벡터 등)의 순위를 병합하는 표준 기법 |
| **리랭킹 (Reranking)** | 1차 검색으로 얻은 상위 후보를 더 정교한 모델로 재정렬하는 단계 |
| **HITL (Human-in-the-loop)** | 최종 판단을 시스템이 아니라 사람(상담원)이 내리도록 설계하는 원칙 |
| **골든셋** | 정답이 라벨링된 평가용 데이터 집합. 검색 정답 문서, 발화 종료 시각, 컴플라이언스 위반 여부 등을 포함 |
| **Recall@5 / MRR** | 검색 품질 지표. Recall@5는 상위 5개 결과 안에 정답이 있는 비율, MRR은 정답이 나온 순위의 역수 평균 |
| **C-5** | 개인정보 실시간 마스킹 모듈. P1~P7 패턴(주민번호·카드번호·계좌번호·휴대전화·인증번호·인명·상세주소)에 대해 누락 0건을 목표로 함 |
| **F-2** | 종결 요건 검증 게이트. 종결형 처리(금융보험의 상품해지·보상, 쇼핑의 반품·교환) 종결 시 필수 근거가 충족됐는지 RAG로 검색·검증하는 모듈. 안내형 도메인(다산콜센터·질병관리본부)에는 적용하지 않음 |
| **데모 도메인 4종** | 이 프로젝트가 실제 데이터로 지원하는 범위: 금융보험(한별금융)·다산콜센터(한별시 통합민원콜센터)·쇼핑(한별샵)·질병관리본부(한별헬스콜). [1.4절](/docs/01/), `_project/decisions/004` |
| **G-2** | 지역 자원 연계 검색(정신건강복지센터·자살예방센터 매칭). 위기 상황 관련 기능 중 유일하게 공개 데이터로 검증 가능 |
| **재현율 우선 설계** | 컴플라이언스·마스킹에서 "놓치는 것"이 "과잉 경고"보다 위험하다는 전제로 정밀도보다 재현율을 우선하는 설계 원칙 |
| **내부 처리 지연 / E2E 체감 지연** | 전자는 트리거 발동부터 카드 표시까지(통제 가능), 후자는 발화 종료부터 카드 표시까지(STT·네트워크 포함, 통제 밖) |
